# Refined Composer

[SDK композиции](../../../docs/extensions/ui-composition.md) · [Установка и обновление пакета](../../../docs/extensions/package-management.md)

Refined Composer меняет рамку, фон, заголовок и подсказку строки ввода в беседе. Зелёный цвет подсказок и акцент рамки берутся из текущей темы. Курсор, горячие клавиши и отправка работают штатно. Требуется ChiselCode 0.6.38 или новее.

В **Настройки → Расширения** установите эту папку, проверьте содержимое и выберите **Доверить и включить**. Если уже установлена версия 1.0.0 с ID `personal.refined-composer`, выберите **Обновить из файла** и укажите эту папку в форме проверки. Отключение в том же меню возвращает стандартное оформление.
