# Студия заметок

Пример SDK v1 для CLI 0.6.38 и новее: самостоятельная панель, поля ввода,
выбор, вкладки на локальных кнопках, Markdown, код, цветная карта с мышью
и клавиатурой, оформление штатного ввода. Модель для управления панелью не нужна.

Установите папку через Настройки → Расширения → Установить, затем
проверьте пакет и выберите «Доверить и включить». `kind: "ui"` активируется
сразу. `requires` предотвращает частичную загрузку в старом host.
Для запуска обновите ChiselCode до 0.6.38 или новее.

Alt+U открывает элементы интерфейса и управление панелью. Tab/Shift+Tab
переходят между элементами, Esc возвращает ввод чату. Alt+S внутри панели
сохраняет заметку через обычный инструмент с подтверждением записи.
Узкий терминал переносит панель над вводом; содержимое прокручивается.

Состояние разделено по беседам и освобождается при отключении. Смена вкладки
и обновление снимка не отправляют сообщения агенту. Файл `studio-note.md`
создаётся только по отдельному действию и после обычной проверки разрешений.
