# Первая задача за несколько шагов

[Документация](README.md) · [Главная](../README.md)

## 1. Установите и запустите

Выберите [установщик для своей платформы](installation.md), затем откройте новый терминал:

```bash
chisel
```

Первый запуск открывает мастер. Найдите провайдера в каталоге и укажите доступную модель. Для API вставьте ключ; для ChatGPT войдите по коду в браузере. Для совместимого API укажите endpoint, если его нет в definition. Подробности — в [справке провайдеров](providers.md).

Повторно открыть мастер можно командой `chisel setup` или через `/settings`. Ключ в мастере скрыт и сохраняется локально в зашифрованном файле.

## 2. Выберите проект

С CLI 0.6.44 запуск с `--launcher` открывает главную без проекта. Выполните `/cwd`, чтобы выбрать папку. В текущих исходниках эта команда также доступна по нажатию `/cwd` внизу главной. При запуске `chisel` из обычного терминала выбирается папка терминала; Git не обязателен. Служебные данные ChiselCode проектом не становятся.

Чтобы сразу указать путь, выполните:

```text
/cwd "C:\path\to\project"
```

На macOS/Linux:

```text
/cwd /home/user/project
```

Путь должен существовать. `/cwd` принимает папку или файл (тогда выбирается его папка); относительный путь отсчитывается от текущего проекта, а без него — от домашней папки пользователя. `/cwd` без аргументов открывает окно выбора. В текущих исходниках список папок обновляется при изменении пути; неполное имя, например `C:\Users\doo`, показывает подходящие папки в родительском каталоге. Недавние проекты в этом окне не выводятся; разговоры доступны через `/resume`.

Tab переводит фокус из пути в список и к действиям. Enter в поле переводит фокус в список, Enter на папке или щелчок переходит внутрь неё. Выберите действие **Открыть папку**, чтобы использовать показанный каталог для задачи. На малом экране действия выбираются стрелками в строке «Действия: …». Esc или Ctrl+C отменяет выбор. Текст задачи сохраняется и не отправляется: отправьте его следующим Enter. Выполненная команда `/cwd` очищается. Модель выбирается через `/model`, подключение настраивается в `/settings`.

## 3. Начните с изучения

```text
Объясни структуру проекта. Найди точку входа и команды для запуска тестов.
```

Затем уточните задачу:

```text
Найди причину ошибки валидации email. Сначала предложи план исправления.
```

Чем точнее ожидаемый результат и способ проверки, тем проще оценить работу помощника.

## 4. Проверьте изменение

При запросе на запись появится diff; для команды — её текст и рабочая папка. **y** разрешает действие, **n / Esc** отклоняет. Попросите запустить нужный тест и показать итоговый diff.

Разрешённый shell не изолирован от системы. Перед подтверждением прочитайте команду; детали — в [модели безопасности](security.md).

## 5. Вернитесь к разговору

`/resume` открывает разговоры всех проектов, в том числе без выбранной папки. Найдите нужный разговор и нажмите Enter: ChiselCode проверит и откроет исходный проект. `/clear` сохраняет текущий разговор и начинает новый, Ctrl+G возвращает на главную, а `/exit` закрывает приложение.

Далее: [команды и клавиши](interactive.md) · [если что-то не работает](troubleshooting.md).

Для второго аккаунта используйте «Новый профиль» в /settings или `chisel setup --provider openai --profile openai-personal`. Выбирайте через --profile; собственный manifest автоматически добавляется в поиск провайдеров.
