# Навыки

[Документация](README.md) · [Главная](../README.md)

Скилл — это папка с `SKILL.md` (формат Agent Skills): YAML-шапка с `name`/`description` и markdown-инструкции. Агент получает только имена и описания доступных ему навыков и по задаче загружает инструкции через `load_skill({name})`. Команда `/имя` вызывает навык вручную, если это разрешено:

```markdown
---
name: explain-api
description: Объясни API проекта, когда пользователь просит описать его контракты.
---

Объясни API по коду проекта. Учти запрос пользователя:

$ARGUMENTS
```

Навыки хранятся в ChiselCode Home: встроенные — в `skills/bundled/`, пользовательские — в `skills/user/`. На Windows ChiselCode Home равен `%LOCALAPPDATA%\ChiselCode`; на macOS/Linux — `$XDG_DATA_HOME/chiselcode` или `~/.local/share/chiselcode`. При обновлении приложение заменяет только встроенные навыки и не трогает `skills/user/`. Проектные каталоги больше не являются источниками навыков. Старые пользовательские навыки безопасно копируются в `skills/user/` при первом обнаружении; исходные файлы сохраняются. Имена встроенных навыков зарезервированы: конфликтующий пользовательский навык игнорируется с диагностикой.

Встроенные команды (`/settings` и др.) перекрыть нельзя. `user-invocable: false` отдельно отключает вызов `/имя`, но оставляет автоматическую загрузку агентом; `disable-model-invocation: true` отдельно скрывает навык от агента, но оставляет ручную команду. Встроенный `/skill-creator` доступен только вручную, а `/code-review` — вручную и по подходящей задаче. `/skill-creator` создаёт и изменяет пользовательские навыки через `create_skill`, который сам ограничивает запись каталогом `skills/user/` и не принимает абсолютные пути. В `/skills` можно закрепить инструкции для всей сессии (`●` — активен). Вложенные `scripts/`, `references/`, `assets/` пока не имеют отдельного загрузчика: агент не может читать их через `load_skill`, а обычный `read_file` ограничен проектом.

## Добавить пользовательский навык

1. Создайте папку `skills/user/explain-api/` внутри ChiselCode Home.
2. Сохраните пример выше в `SKILL.md` этой папки.
3. Откройте `/skills` и проверьте, что навык обнаружен; при необходимости перезапустите приложение.
4. Вызовите `/explain-api опиши публичные endpoints` или закрепите навык через `/skills`.

Для создания через помощника используйте `/skill-creator`. Перед сохранением проверьте предложенные инструкции. Навык добавляет инструкции, но не отменяет подтверждения инструментов и проверки путей.

| Поле YAML | Назначение |
| --- | --- |
| `name` | Имя навыка и ручной команды |
| `description` | Когда агенту следует использовать навык |
| `user-invocable: false` | Отключить ручной вызов |
| `disable-model-invocation: true` | Отключить автоматический выбор агентом |

См. также: [расположение данных](configuration.md), [безопасность](security.md).
