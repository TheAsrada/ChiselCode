# Горячие клавиши

[Документация](README.md) · [Интерактивный режим](interactive.md) · [Сессии](sessions.md)

Сочетания зависят от фокуса: в основном чате, боковой панели и открытом окне одна клавиша может выполнять разные действия. Окно подтверждения или настроек обрабатывает ввод раньше чата. Клавиши подтверждения указаны латиницей; явно перечисленные русские варианты также поддерживаются. Локальные действия меню выбираются по названию через Tab, стрелки и Enter.

Быстрые переходы: [чат](#чат-и-ввод) · [вкладки](#вкладки-разговоров) · [лента](#лента-действия-и-diff) · [панель](#боковая-панель) · [помощники и фон](#помощники-и-фоновые-задачи) · [сервисы](#состояния-сервисов) · [окна](#настройки-модели-навыки-и-сессии) · [подтверждения](#подтверждение-действий).

## Основные сочетания

В текущих исходниках первый Enter с задачей без проекта открывает выбор папки и сохраняет текст. В окне выбора Tab/Shift+Tab меняет область, стрелки и PgUp/PgDn — строку списка. Enter в поле пути переводит фокус в список; Enter на строке переходит в папку. Действие «Открыть папку» подтверждает выбор проекта; Esc/Ctrl+C отменяет операцию этого окна. Выбор проекта не отправляет задачу. В архивном просмотре Esc возвращает к списку, не продолжая сессию.

Эти действия доступны с главной и из основного чата, когда ввод не занят другим окном. Подсказка F7/F8/F9 на главной — обычный текст; служебных кнопок под вводом нет.

| Клавиши | Действие |
| --- | --- |
| **Enter** | Отправить сообщение; во время работы агента — поставить следующее сообщение в очередь |
| **Shift+Enter** | Добавить строку в сообщение |
| **Shift+Tab** | Переключить **Plan / Build** для следующего сообщения |
| **F4** | Переключить **Manual / Accept edits / Dont ask / Bypass** для следующего сообщения; недоступный Bypass пропускается |
| **Ctrl+C** | Остановить основную работу, очередь и принадлежащие текущему разговору задачи; остальные вкладки продолжают работу |
| **Ctrl+S** | Открыть библиотеку навыков, сохранив черновик сообщения |
| **Ctrl+,** | Открыть настройки |
| **Ctrl+T** | Открыть «Внешний вид» → «Тема» в настройках |
| **Ctrl+B** | Показать или скрыть боковую панель на текущем экране |
| **F6** | Открыть сохранённый или текущий побочный ответ, если он есть |
| **F7** | Открыть дерево помощников |
| **F8** | Открыть фоновые задачи, в том числе во время работы агента |
| **F9** | Открыть состояния сервисов и расширений |

Для выхода отправьте `/exit`. `Ctrl+C` в чате останавливает работу, сохраняя разговор. В окнах просмотра помощников и фоновых задач `Ctrl+C` не запускает групповую остановку: выберите действие «Остановить».

## Чат и ввод

| Клавиши | Действие |
| --- | --- |
| **Ctrl+P / Ctrl+N** | Предыдущее / следующее отправленное сообщение; возврат из истории восстанавливает черновик |
| **↑ / ↓** | История сообщений, если курсор находится на первой / последней строке ввода; внутри многострочного текста — движение курсора |
| **Ctrl+V**, **Ctrl+Shift+V**, **Shift+Insert** | Вставить текст в выбранное поле; вставка из ленты возвращает фокус в сообщение |
| **Ctrl+Shift+C**, **Ctrl+Insert** | Скопировать выделенный текст чата или ввода |
| **↑ / ↓** при открытых slash-подсказках | Выбрать команду; эти клавиши временно управляют подсказками вместо истории |
| **Tab** при открытых slash-подсказках | Дополнить выбранную команду |
| **Enter** при неполной slash-команде | Дополнить выбранную команду; после ввода аргументов повторный Enter отправляет её |
| **Esc** при открытых slash-подсказках | Скрыть подсказки |

Многострочная вставка сама по себе не отправляет сообщение. Выделение текста ленты мышью копирует его; правый щелчок по выделению копирует и снимает выделение, а без выделения вставляет текст. Открытое окно сохраняет собственное поле вставки. Подробнее о вводе и прокрутке — в [интерактивном режиме](interactive.md#клавиши-и-прокрутка).

### Редактирование сообщения

| Клавиши | Действие в поле ввода |
| --- | --- |
| **← / →**, **Backspace / Delete** | Движение курсора и удаление символов |
| **Shift+← / Shift+→** | Выделить текст |
| **Ctrl+← / Ctrl+→** | Перейти на слово назад / вперёд |
| **Ctrl+A / Ctrl+E** | Перейти в начало / конец текущей строки |
| **Ctrl+Backspace / Ctrl+Delete** | Удалить слово назад / вперёд |
| **Ctrl+U / Ctrl+K** | Удалить текст от курсора до начала / конца строки |
| **Ctrl+- / Ctrl+.** | Отменить / повторить редактирование |

Сочетания интерфейса имеют приоритет над стандартными сочетаниями редактора: Ctrl+B управляет панелью, Ctrl+D — diff, Ctrl+W — вкладкой. В терминалах, передающих модификатор **Cmd/Super**, также доступны Cmd+C/V для буфера, Cmd+A для выделения всего текста и Cmd+Z / Cmd+Shift+Z для отмены / повтора.

## Вкладки разговоров

| Клавиши | Действие |
| --- | --- |
| **Alt+N** или **Ctrl+Shift+N** | Открыть стартовый экран для новой задачи; вкладка создаётся при отправке сообщения |
| **Alt+← / Alt+→** | Предыдущая / следующая открытая вкладка |
| **Ctrl+Shift+Tab / Ctrl+Tab** | Предыдущая / следующая открытая вкладка |
| **Ctrl+G** | Вернуться на стартовый экран |
| **Ctrl+W** | Закрыть текущую вкладку; сохранённая история остаётся доступной |
| **Esc** в свободном поле чата | Вернуться на стартовый экран; если открыт просмотр или фокус находится в панели, сначала выйти из него |

Переключение вкладок доступно и при ожидающем подтверждении: ответ остаётся привязан к исходной вкладке. Новая вкладка и переход на главную сохраняют уже отправленные задачи. Закрытие вкладки связано с остановкой её работы; отдельные побочные операции могут потребовать предварительного завершения или остановки. [История и продолжение разговоров](sessions.md).

## Лента, действия и diff

| Клавиши | Где и что делают |
| --- | --- |
| **Tab** | Из ввода перейти в ленту, затем в боковую панель, если она видима, и обратно; на главной лента отсутствует |
| **Tab / Shift+Tab**, **↑ / ↓** | При фокусе в ленте выбрать сводку, вывод, страницу результата или запись побочного ответа |
| **Enter / Space** | Раскрыть или свернуть выбранную сводку / вывод, перейти на выбранную страницу; открыть выбранную запись побочного ответа |
| **PgUp / PgDn** | Прокрутить историю; при достижении границы окна показать более ранние или поздние записи |
| **End** | Перейти к последним сообщениям |
| **Ctrl+D** | Раскрыть или свернуть последний diff |
| **Esc** | Закрыть просмотр diff либо вернуть фокус из ленты к вводу |

Колесо мыши работает в ленте и предпросмотрах. Подробности сводок открываются внутри чата; полный результат читается страницами без нового запроса модели. [Действия агента и навыки](agent-actions.md).

## Боковая панель

Клавиши этого раздела действуют, когда панель в фокусе. В поле сообщения и поиске меню цифры и скобки продолжают вводить текст.

| Клавиши | Действие |
| --- | --- |
| **Tab / Shift+Tab**, затем **← / →** на полосе разделов | Выбрать «Меню» / «Контекст» / «Агенты» |
| **↑ / ↓**, **Home / End**, **PgUp / PgDn** | Выбрать пункт меню или прокрутить содержимое текущего раздела |
| **Enter / Space** в «Меню» | Открыть выбранный пункт |
| **/** в «Меню» | Искать действие по названию, описанию, разделу или команде |
| **Tab / Shift+Tab** | Обойти поиск, содержимое, действия и полосу разделов |
| **Esc** | Вернуться в чат |

Enter открывает выбранный пункт меню и сохраняет черновик. В поиске Esc завершает ввод и очищает непустой запрос; следующий Esc возвращает в чат. В оформлении выберите действие «Анимации» для переключения плавности. [Устройство панели](interactive.md#боковая-панель).

## Помощники и фоновые задачи

### Помощники

Откройте дерево через **F7**; подробности выбранного помощника — через Enter.

| Клавиши | Где и что делают |
| --- | --- |
| **↑ / ↓**, **Home / End**, **PgUp / PgDn** | Выбрать помощника в дереве; стрелки и постраничные клавиши прокручивают открытые подробности |
| **← / →** | В дереве свернуть / развернуть ветви; на полосе разделов подробностей переключить ход работы, изменения и итог; в действиях выбрать кнопку |
| **Tab / Shift+Tab** | Выбрать действие или вернуться к содержимому |
| **Enter** | Открыть выбранного помощника или выполнить выбранное действие |
| **Tab**, затем стрелки и **Enter / Space** | Выбрать «Остановить», «Контекст» или другое доступное действие |
| **Esc** | Вернуться из подробностей к дереву или из дерева в чат |
| **F7** в дереве | Вернуться в чат |

[Поручения, изменения и остановка помощников](subagents.md).

### Фоновые задачи

Откройте список через **F8**, `/tasks` или «Меню → Фоновые задачи».

| Клавиши | Где и что делают |
| --- | --- |
| **↑ / ↓**, **Home / End**, **PgUp / PgDn** | Выбрать задачу в списке; в подробностях стрелки и постраничные клавиши прокручивают вывод |
| **Enter** | Открыть задачу или выполнить выбранное действие |
| **Tab / Shift+Tab** | Выбрать действие |
| **Tab**, затем стрелки и **Enter / Space** | Выбрать «Остановить», «Фильтр» или другое именованное действие |
| **/** | В списке искать по названию или команде; в подробностях — искать в выводе |
| **«Остановить все…»**, затем **Enter** | Подтвердить остановку захваченного набора активных задач текущего разговора; Esc отменяет |
| **← / →** на полосе разделов подробностей | Переключить «Вывод / Сведения / Итог» |
| **Shift+← / Shift+→** в подробностях | Прокрутить длинные строки горизонтально |
| **Действия → «В фон» / «Восстановить очистку»** | Перевести foreground-команду в фон или проверить очистку, если действие доступно |
| **Esc** | Выйти из поиска или просмотра к предыдущему экрану |

Поиск доступен также через Tab; буквы и пробелы остаются текстом поля. Удаление и восстановление истории выбираются через доступные действия окна. [Вывод, история и управление процессами](background-tasks.md).

## Состояния сервисов

**F9** или **Меню → Состояние сервисов** открывают список статусов LSP, фоновых задач, помощников и расширений. ↑/↓ выбирают строку, Enter или щелчок открывает её подробности, Esc закрывает список. Ctrl+C внутри окна не отменяет основную работу. Открытое подтверждение или другой диалог не пропускает F8/F9 к чату.

## Настройки, модели, навыки и сессии

Окно сообщения команды на главной закрывается Enter, Esc, Ctrl+C или кнопкой «Закрыть». ↑/↓ и PgUp/PgDn прокручивают длинный результат, Home/End переходят к началу/концу. Ввод и вставка не попадают в поле сообщения за этим окном.

Общее правило окон: **Esc** возвращает на уровень назад или закрывает окно, **Tab / Shift+Tab** переключают доступные области или действия. Конкретные исключения перечислены ниже.

| Окно | Управление | Действие |
| --- | --- | --- |
| Все меню | **Tab / Shift+Tab** | Обход подразделов, поиска, содержимого и действий; пустые и недоступные действия пропускаются |
| Полоса подразделов | **← / →** | Сменить подраздел без выполнения операции |
| Список | **↑ / ↓**, **Home / End**, **PgUp / PgDn** | Выбрать строку или прокрутить содержимое; в поле Home/End принадлежат редактору |
| Действия | Стрелки, **Enter / Space** | Выбрать и выполнить именованное действие; на малом экране строка «Действия: …» показывает выбранную операцию |
| Настройки | **Ctrl+F** | Найти раздел или поле; внутри содержимого LSP — найти сервер |
| Settings | Автосохранение | Выбор сохраняется сразу; текст — после валидации, Enter или выхода из поля. При ошибке ввод сохраняется |
| Анализ кода · LSP | **Enter**, **Space**, **Esc** | Открыть карточку, изменить переключатель, вернуться; валидная ручная форма сохраняется автоматически |
| Расширения | **Enter / Space**, **Esc**, **/** | Открыть карточку или действие, вернуться, перейти к поиску каталога |
| Оформление | **/**, действия | Найти тему; Enter или щелчок сохраняет тему, стрелки дают предпросмотр; «Анимации» |
| Модели | Полоса «Модели / Профили», действия | «Выбрать», «Ввести ID», «Обновить каталог», «Настройки» |
| Выбор папки | Поле пути, список, действия | Автоматическое дополнение пути; Enter переходит в список или папку, «Открыть папку» выбирает проект, «Ещё папки» читает следующую порцию |
| Навыки, отдельно и в Settings | Полоса «Библиотека / Закрепление», действия | «Применить к задаче» / «Закрепить», «Инструкции», «Создать», «Изменить», «Обновить каталог» |
| История | Действия выбранной строки | «Продолжить», «Просмотр», «Переименовать», «Удалить…»; Y/Н подтверждают удаление, другая клавиша отменяет |
| MCP | Именованные действия | «Проверить подключение», «Остановить проверку», «Добавить, доверить и подключить»; разрешения сохраняются сразу |
| MCP | **Esc / Ctrl+C** | Отменить проверку; Esc также возвращает на предыдущий экран |
| Побочный ответ | **F6 / Esc**, **Tab**, **Enter** | Скрыть окно или выбрать действие, включая «Остановить ответ» |
| Разрешения | **↑ / ↓**, **Enter** | Выбрать режим; «Настройки» доступно через Tab и Enter |

F2, F3, локальные Ctrl+N/O/E/R/P/D, Alt+1/2 и буквенные команды управления меню удалены. Глобальные сочетания чата и клавиши подтверждения ниже сохранены. В полях снятое сочетание может выполнять стандартное действие редактора.

Ввод текста в поисковое поле фильтрует список. При поиске в истории Esc сначала очищает строку, повторный Esc закрывает окно. Изменение навыка доступно для пользовательских навыков; выбор в библиотеке сам по себе не отправляет сообщение. Подробнее: [навыки](skills.md), [модели](providers.md), [сессии](sessions.md), [разрешения](permissions.md), [побочные вопросы](side-questions.md).

## Подтверждение действий

| Клавиши | Действие |
| --- | --- |
| **Y** или **Н** | Разрешить одно действие |
| **N**, **Т** или **Esc** | Отказать |
| **A** или **Ф** при сетевом подтверждении | Разрешить поиск или указанный домен на текущую сессию, если этот вариант предложен |
| **S** при подтверждении инструмента помощника | Остановить этого помощника, если действие доступно |
| **↑ / ↓**, **PgUp / PgDn**, **Home / End** | Прокрутить команду, diff или другое содержимое предпросмотра |

F4 внутри подтверждения не переключает режим разрешений. Выбранный режим и язык навыка не отменяют подтверждений отдельных операций. [Правила разрешений](permissions.md).

## Действия интерфейса расширений

Начиная с 0.6.33 **Alt+U** открывает кнопки UI-модов в отдельном списке. Начиная с 0.6.38 список включает поля, выбор, интерактивные области и сворачивание панелей. ↑/↓ и Tab выбирают элемент, Enter выполняет действие или передаёт фокус полю.

В форме **Tab / Shift+Tab** переходят между элементами, **Enter** подтверждает поле или выбор, **Esc** возвращает в чат. Собственные сочетания расширения действуют в его области; обычные буквы не перехватывают набор текста в другом поле. Ctrl+C, управление вкладками, настройки и подтверждения сохраняют приоритет. [Создание и включение UI-мода](ui-mods.md).

## Если сочетание не срабатывает

Терминал или оконный менеджер может перехватывать **Shift+Enter**, **Ctrl+Tab**, **Ctrl+Shift+Tab**, **Ctrl+Shift+N** или **Ctrl+,**. Сначала проверьте фокус и открытые окна. Затем используйте мышь или команды: `/settings`, `/skills`, `/clear`, `/resume`, `/permissions`. Вкладки также переключаются через Alt+←/→. Для многострочного сообщения можно вставить уже подготовленный текст.

В split-footer (`CHISEL_NO_ALT_SCREEN=1` или `CHISEL_ALT_SCREEN=0`) завершённая история находится в нативной прокрутке терминала. Tab открывает интерактивную ленту в области OpenTUI; прокрутка терминала и ленты управляет разными областями.

В 0.6.34 переключатель «Графика» удалён. Ctrl+G в оформлении больше не меняет вид; в чате Ctrl+G по-прежнему открывает главную. [Настройки интерфейса](configuration.md#параметры-интерфейса).
