# Архитектурное решение — встроенный браузер

[Архитектура](../architecture.md) · [Руководство](../browser.md) · [Проверки](../contributors/testing.md)

## Активация и владение

`builtin.browser` регистрируется через Extension Host. Расширение содержит schemas инструментов, команду `/browser`, service и `pane/sidebar`. Кнопки и команда исполняют own tools через `ToolExecutor` с guards, preview и live recheck. Панель не занимает место до открытия командой `/browser`, в том числе пока готовится её первый snapshot. `status` и `diagnostics` читают кэш наблюдений. Навигация, viewport, интеракции и работа с живым документом требуют Build и соответствующего подтверждения.

Scope канонического workspace хранит сервис. Состояние страницы привязано к ID и сигналу живого владельца разговора. Это позволяет сохранять вкладки между запросами и очищать их при закрытии вкладки ChiselCode. Headless передаёт сигнал с временем жизни вызова. В результате `resume` поднимает новую генерацию только при активном вызове. Закрытие вкладки Chromium и отключение расширения убирают её ссылки на элементы. Неподтверждённая очистка блокирует конфликтующий запуск и отмечается в каталоге для активации workspace. Вкладки создаются в эфемерном контексте Chromium с ограничениями на число владельцев, вкладок и ожидающих действий.

## Поставка

Базовый CLI содержит код сервиса и schema. По явному действию скачиваются два закреплённых архива Playwright 1.65.1 и Chrome Headless Shell 159.0.815.4.6. Установщик проверяет их SHA-512 и SHA-256, распаковывает во временный каталог и переименовывает его под блокировкой хранилища. В исходниках, npm и compiled runtime использует один и тот же приватный кэш. Playwright загружается по абсолютному пути из кэша через Bun. Chromium устанавливается для Linux x64, а в запуске используются системные Bubblewrap и Python 3. Для распаковки нужен `unzip`.

## Исходящие соединения

Bubblewrap запускает Chromium и локальный relay в отдельных Linux user, PID и network namespaces. У Chromium включён собственный sandbox. Профиль эфемерен, окружение собрано из разрешённых переменных, пользовательские каталоги и токены ChiselCode не монтируются. Relay слушает loopback внутри namespace и передаёт байты в приватный Unix-сокет. Хостовый HTTP proxy открывает соединение только к закреплённому числовому loopback и порту, проверяет фактического peer и конфигурацию перед каждым запросом. DNS для локальных назначений не используется. Для CONNECT допускается строго ограниченный WebSocket upgrade на этот же адрес. При отзыве доступа закрываются и ранее открытые потоки. Service workers, QUIC, внешние протоколы, скачивания, передачи файлов, выдача device permissions и произвольные JS/CDP-инструменты исключены из доступного сценария.

Публичный просмотр закрыт до отдельной проверки политики DNS и закрепления публичных IP на всех маршрутах. Headed требует отдельной проверки безопасного доступа к графическому сеансу. Доступная проверка использует локальные серверы с измерением фактических попаданий.

## Снимки

Playwright маскирует поля, элементы `[data-private]` и дополнительные области по запросу. PNG записывается с правами владельца, хранится до 15 минут и удаляется при обычном завершении владельца. Текстовый результат содержит file URI, размер и состояние передачи. Превью имеет собственные лимиты cache/renderer SDK.

Для подключений подписки с явным пользовательским opt-in и заявленной моделью поддержкой image есть отдельный in-memory порт. Он передаёт один PNG размером до 256 KiB отдельно от JSON содержимого tool result. Модель получает PNG только с ближайшим соответствующим результатом. Перед отправкой повторно проверяются профиль, рабочий origin и активность расширения. ChatGPT subscription adapter кодирует байты на границе транспорта. История, checkpoints, логи результатов и SDK hooks модели получают текст. Сериализация подписки проверяется отдельно. Публичный OpenAI Responses API и реальная inference-проверка vision требуют отдельных проверок.
