# Навыки из MCP

[Документация](../README.md) · [Архитектура](../architecture.md) · [Руководство](../skills.md#навыки-из-mcp)

Статус: принято, текущие исходники.

## Решение

Подключённый MCP-сервер публикует свои инструкции по стандарту [Skills over MCP](https://modelcontextprotocol.io/extensions/skills/overview). ChiselCode добавляет метаданные в текущую проекцию команд и библиотеку. ID из конфигурации формирует имя `сервер:навык`, а URI связывает запись с конкретным ресурсом этого подключения.

Сетевое обнаружение и проверка файлов отделены от локальной установки. Навык сервера не копируется в ChiselCode Home и не получает доступа к операциям редактирования и закрепления. Вызов вручную применяет инструкции только к текущему запросу. Справочные файлы читаются через `load_skill` в рамках этого вызова.

## Модули

| Модуль | Ответственность |
| --- | --- |
| `src/mcp/skills.ts` | Схемы расширения, проверка манифеста, разрешение относительных путей, целостность файлов и соответствие YAML-шапки. |
| `src/mcp/transports.ts` | Согласование capability и передача `skills/list`, `skills/get`, `resources/read` через SDK. |
| `src/mcp/manager.ts` | Метаданные на время подключения, имена по ID сервера, отмена ожидания и контроль владельца при чтении. |
| `src/skills/mcp.ts` | Проекция записи для каталога, разбор команды и пометка происхождения в пользовательском сообщении. |
| `src/ui/workspace-commands.ts`, `src/ui/opentui-skills.tsx` | Общая проекция команд, реакция на изменение каталога и просмотр инструкций по запросу. |
| `src/app/tool-runtime.ts`, `src/tools/local/skills.ts` | Загрузка навыка при запуске и чтение справочных файлов из манифеста этого вызова. |

## Жизненный цикл

После подключения менеджер начинает ограниченное по времени чтение списка. Сбой каталога отражается в журнале сервера и не меняет состояние его tools. Одновременные запросы каталога используют общую операцию. При отключении или смене подключения записи удаляются, а ответы старого соединения не публикуются в новом каталоге.

При вызове клиент уточняет манифест через `skills/get` и читает `SKILL.md` через исходное соединение. Для каждого запрошенного файла проверяются исходные байты. Поддерживаются только файлы из зафиксированного манифеста и относительные пути внутри навыка. Содержимое прикладывается к сообщению пользователя с указанием происхождения. Заготовка команды и просмотр текста не создают запрос модели.

Shell, Git-запись и делегирование после использования серверного навыка требуют подтверждения в рамках этого разговора. Plan и существующие запреты сохраняются. [Политика безопасности](../security.md#mcp).
