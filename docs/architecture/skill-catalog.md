# Каталог локальных навыков

[Документация](../README.md) · [Архитектура](../architecture.md) · [Руководство](../skills.md)

Статус принят в текущих исходниках.

## Загрузка и проекции каталога

`src/skills/skills.ts` проверяет все записи каталогов `skills/user` и `skills/bundled`. Для `SKILL.md` сохраняются границы имени, типа и размера файла. Модуль `frontmatter.ts` использует YAML-парсер с проверкой дублирующихся ключей и ограничением раскрытия ссылок. Локальные файлы без шапки сохраняют прежний вывод имени из папки и описания из первой строки. Повреждённая шапка диагностируется до публикации записи. Загрузка, создание и установка используют один разбор метаданных.

В OpenTUI полная библиотека поддерживает поиск, просмотр и выбор навыков. Проекция команд использует `user-invocable`. Модельная проекция и поиск используют `disable-model-invocation`. Модуль `catalog.ts` формирует блок `<available_skills>` до 8 KiB по фактическому UTF-8 после экранирования и ограничивает каждое описание 240 байтами до экранирования. Встроенные навыки имеют приоритет начального показа. Модель получает остальные доступные ей записи через `search_skills` с лимитом в 12 записей на страницу. Поиск сопоставляет фильтр с полным описанием из библиотеки и возвращает короткую выдержку.

## Доступ по явному вызову

При отправке `/имя` OpenTUI выбирает запись из текущей проекции ручных команд и передаёт её в композицию runtime вместе с развёрнутым сообщением. Runtime включает доступ к файлам при подготовке первого обращения к модели, после обработки незавершённых вызовов из прежней истории. Пока выполняется этот запрос, `load_skill({name, path})` сверяет имя, источник и каталог выбранного навыка с текущей записью библиотеки. Применяются общие проверки относительного пути, symlink, размера и UTF-8. Закреплённые навыки и текст сохранённых сообщений не дают этого доступа.

`search_skills` и `load_skill` проходят обычный read-only executor. Политика помощников допускает оригинальные штатные handlers после аттестации. Общие правила Plan, разрешений, установки и записи описаны в [runtime](runtime.md). Для MCP действует [контракт ресурсов](mcp-skills.md).
