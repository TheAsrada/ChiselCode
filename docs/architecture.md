## Путь запроса

```mermaid
flowchart TD
  CLI["CLI и интерактивный интерфейс"] --> Run["Подготовка сессии и контекста"]
  Run --> Loop["Агентный цикл"]
  Loop <--> API["Адаптер провайдера"]
  Loop --> Tools["Реестр инструментов"]
  Tools --> Gate["Проверки путей и разрешений"]
  Gate --> Result["Выполнение и результат"]
  Result --> Loop
  Loop --> Store["Сохранение сессии"]
  Store --> UI["Ответ и diff в интерфейсе"]
```

`runPrompt` загружает настройки проекта, сессию, ключ и провайдера. Системная инструкция объединяет правила `CHISEL.md`, динамический контекст проекта и каталог навыков. Агентный цикл получает ответ модели, выполняет разрешённые вызовы инструментов и сохраняет контрольные точки сессии.

## Контракты, которые важно сохранить

- `ProviderAdapter` отделяет агентный цикл от протокола API.
- `ApprovalGate` централизует решение о разрешении изменяющих инструментов.
- `FileDiff` передаётся отдельным полем; UI не восстанавливает его из окрашенного текста.
- Данные отображения diff сохраняются в сессии отдельно от сообщений провайдера.
- Разговоры связаны с проектом; пользовательские навыки живут в ChiselCode Home.

## Главная и вкладки терминала

`TuiWorkspace` хранит отдельный `TuiController` для главной и каждой открытой вкладки. Контроллер владеет папкой проекта, черновиком, лентой, потоковым ответом, расходом контекста и состоянием прокрутки. `OpenTuiSpike` выбирает активный экран, а `SessionTabs` и `OpenTuiHome` отображают навигацию. Черновик становится сохранённой сессией после первого выполненного запроса; повторное открытие сессии выбирает существующий контроллер. Закрытие вкладки освобождает экран, не удаляя файл разговора.

Агент выполняет один запрос за раз. Очередь хранит текст вместе с исходным контроллером; обработчики ответа используют этот же контроллер независимо от выбранной вкладки. Незавершённые вкладки нельзя закрыть или удалить через историю. Смена проекта на главной не меняет папки открытых вкладок. Подтверждения по-прежнему показываются поверх интерфейса и требуют прежнего решения пользователя.

Поведение сверено с OpenCode: [главная TUI](https://github.com/anomalyco/opencode/blob/2fa3363c924c5c3e367b84a87ae478296a0ed59b/packages/tui/src/routes/home.tsx), [главная приложения](https://github.com/anomalyco/opencode/blob/2fa3363c924c5c3e367b84a87ae478296a0ed59b/packages/app/src/pages/home.tsx), [модель вкладок](https://github.com/anomalyco/opencode/blob/2fa3363c924c5c3e367b84a87ae478296a0ed59b/packages/app/src/context/tabs.tsx) и [верхняя навигация](https://github.com/anomalyco/opencode/blob/2fa3363c924c5c3e367b84a87ae478296a0ed59b/packages/app/src/components/titlebar.tsx). Для терминала ChiselCode сохранены разделение главной и разговора, вкладки-черновики, создание через «+» и закрытие без удаления истории; управление дополнено клавишами, работающими в обычном терминале.
