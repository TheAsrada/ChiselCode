# Боковая панель OpenTUI

Панель объединяет меню приложения, контекст разговора и дерево помощников. Выбор раздела, фокус и временное открытие принадлежат текущему `TuiController`; поступление новых событий помощника сохраняет явно выбранную вкладку. Скролл контекста и меню хранится отдельно для каждой беседы и сбрасывается при смене сессии или проекта.

Основа дизайна — постоянная полоса вкладок, выделение выбранного раздела, независимая прокрутка и явный фокус. У модели и контекста отдельные блоки; состояния помощников используют цвета темы, а запрос разрешения дополнительно отмечен `!N`. При неизвестном окне процент отсутствует. ASCII и графика следуют настройке приложения.

Изученные первичные источники:

- [OpenTUI TabSelect](https://opentui.com/docs/components/tab-select/) — постоянные варианты, выделение выбора, переключение стрелками или скобками.
- [OpenTUI interaction](https://opentui.com/docs/core-concepts/interaction/) — один native focus, явная маршрутизация клавиатуры и событий мыши.
- [OpenTUI ScrollBox](https://opentui.com/docs/components/scrollbox/) — отдельный viewport, клавиатура, колесо и показ выбранной строки.
- [Пример TabSelect](https://github.com/anomalyco/opentui/blob/main/packages/examples/src/tab-select-demo.ts) — навигация рядом с отдельным содержимым.
- [Контекстная панель OpenCode](https://github.com/anomalyco/opencode/blob/dev/packages/tui/src/feature-plugins/sidebar/context.tsx) — компактные показатели модели и контекста.

Реализация проверена с установленным OpenTUI 0.5.12. Полоса собрана из native `box`/`text`: это позволяет распределить три раздела в 40 колонках и согласовать их с владельцем ввода приложения. `ContextSidebar` использует native фокус прокрутки; меню и дерево явно обрабатывают клавиши. Общая полоса сохраняет ширину чата и не подписывает каждый блок на изменение размеров терминала.

`SidebarMenu` вызывает существующие обработчики окон и команд; разрешения и исполнение инструментов остаются в runtime. Sidebar не запускает помощников при открытии дерева. Закрытие панели сохраняет черновик.

Интерактивные проверки: вкладки мышью и клавиатурой, открытие настроек из меню, изоляция ввода диалога, сохранение черновика и выделенного помощника при streaming, независимая прокрутка, правое наложение и полный узкий экран, четыре темы. Fixture `tests/fixtures/tui-subagents.ts` дополнительно открывает меню и настройки через `runOpenTuiAgent` с настоящей делегацией, инструментами, Git и сохранёнными сессиями; этот же сценарий включён в проверки установленного пакета и compiled-сборки.

Для воспроизводимых кадров:

```sh
CHISEL_SIDEBAR_CAPTURES=/tmp/chisel-sidebar bun test tests/unit/opentui-sidebar.test.tsx
CHISEL_CAPTURE_DIR=/tmp/chisel-runtime bun tests/fixtures/tui-subagents.ts
```

Файлы `.txt` содержат символы реального кадра, `.json` — native spans с цветами и атрибутами. Обычный запуск CLI не использует эти переменные.

Управление описано в [интерактивном режиме](../interactive.md#боковая-панель).
