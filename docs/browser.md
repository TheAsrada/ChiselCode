# Браузер для проверки интерфейса

[Документация](README.md) · [Разрешения](permissions.md) · [Устройство браузера](architecture/browser.md)

Встроенный `builtin.browser` доступен с CLI 0.6.59 на Linux x64. После установки или обновления расширение включено, если вы ранее его явно не выключали. Chromium нужен только для действий с живой страницей.

## Открыть локальное приложение

1. Запустите dev-сервер на loopback, например на `127.0.0.1:5173`.
2. Добавьте адрес в пользовательский `config.json` (на Linux обычно `~/.config/chiselcode/config.json`). Сохраните остальные поля файла. Список `browser.origins` разрешает конкретные HTTP origin с портом.

   ```json
   {
     "schemaVersion": 2,
     "profiles": {},
     "browser": { "origins": ["http://127.0.0.1:5173"] }
   }
   ```

3. Откройте проект и выполните `/browser` в OpenTUI. Если Chromium отсутствует, переключитесь в Build, выберите **Установить Chromium** и подтвердите загрузку. Команда `/browser install` выполняет ту же операцию. [Требования Linux и кэш](installation.md#браузер-для-frontend-qa).
4. Введите URL в поле **Адрес**. **Открыть** показывает запрос разрешения с origin и действием. Также можно выполнить `/browser open http://127.0.0.1:5173/`. Адрес `localhost` нормализуется в `127.0.0.1`. Для IPv6 используйте `http://[::1]:<порт>`.

На широком терминале панель находится справа от чата. На узком она переносится над вводом и прокручивается. Мышь или **Alt+U** переводит фокус на элемент панели, **Tab / Shift+Tab** переключает элементы, **Esc** возвращает в чат. Повторный `/browser` скрывает панель. Кнопка **Закрыть** закрывает выбранную вкладку Chromium. Браузер закрывает профиль после последней вкладки, при закрытии беседы, отключении расширения или выходе. `/resume` открывает историю с новым браузерным профилем при первом вызове.

Выключатель находится в **Настройки → Расширения → Браузер → Выключить**. В этой же карточке выберите **Включить** для возврата. В `.chiselrc` можно задать `"browser": {"enabled": false}` или сузить список `browser.origins`. Удаление адреса из разрешённого списка закрывает активный профиль для этого адреса.

## Проверить и повторить сценарий

```text
Открой разрешённый локальный адрес. На телефоне и десктопе
заполни форму и отправь её. Проверь горизонтальное переполнение,
Console и Сеть. Исправь в проекте причину дефекта, обнови вкладку
и повтори тот же сценарий на обеих ширинах. Сравни наблюдения.
```

- Пресеты **Телефон** (390 × 844), **Планшет** (768 × 1024), **Десктоп** (1280 × 800) меняют размеры viewport в Chromium. Инструмент также принимает явные размеры.
- Снимок доступности показывает элементы и текущие ссылки на цели. При смене документа или обновлении снимка получите новые ссылки. Строгий CSS-селектор должен находить один элемент.
- Вкладки **Console** и **Сеть** показывают свежие события. Агент может читать ограниченные журналы по курсору, искать ошибки JS и анализировать вычисленные стили, границы элемента и overflow.
- **Снимок** сохраняет маскированный PNG. Доступны viewport, область элемента или страница в пределах 1600 × 1200. Превью появляется, если PNG укладывается в лимит панели. URI указывает на приватный локальный файл сроком до 15 минут или до закрытия разговора, смотря что наступит раньше.
- Профиль поддерживает вкладки одного разрешённого origin. Чтобы перейти на другой порт, закройте вкладки текущего адреса. Подресурсы и WebSocket другого origin блокируются.
- В Plan доступны собранные состояния и журналы. В Build активные действия проходят обычные подтверждения. Headless использует те же инструменты, профили и правила. [Режимы разрешений](permissions.md).

## Передать снимок модели

По умолчанию инструмент возвращает текст и локальный PNG. Если хотите разрешить передачу снимков модели подписки ChatGPT, добавьте ID нужного подключения в `browser.imageProfiles` в пользовательском `config.json`. Агент должен запросить `modelImage: true`, а каталог модели должен объявить поддержку `image`. Используйте `mask` с CSS-селектором для дополнительных чувствительных областей. В ответе `modelImage: "unavailable"` означает, что модель получит текстовый результат. Передача изображения через публичный Responses API здесь не подключена.

Публичные адреса, HTTPS, headed Chromium и macOS/Windows пока недоступны. В этом режиме страница выполняет свой JavaScript и может изменять состояние разрешённого dev-сервера. Открывайте тестовое приложение с подходящими данными.
