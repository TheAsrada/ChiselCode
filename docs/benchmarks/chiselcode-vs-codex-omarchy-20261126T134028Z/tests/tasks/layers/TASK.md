# Задача

Восстанови `resolve(defaults, layers, env)` в `solution.py`. Это конфигурация локального приложения.
Все три аргумента — JSON-совместимые. Layers — список словарей в порядке от слабого к сильному.
Рекурсивно объединяй словари, если в обеих сторонах словарь. Остальные значения, включая списки, заменяй.
Внутри слоя значение null удаляет ключ. Когда словарь заменяет скаляр или создаётся с нуля, эти удаления
тоже действуют. Null из defaults сохраняй. Затем обработай env в лексикографическом порядке имён.
Учитывай только имена APP__ с непустыми сегментами, разделёнными __. Приводи сегменты к нижнему регистру.
Каждое значение разбирай как JSON, а при ошибке оставляй строкой. Env присваивает значение целиком, включая
null и словарь, и создаёт промежуточные словари при необходимости, заменяя скаляры. Входы не меняй и не
разделяй с результатом изменяемые объекты.

Публичные проверки запускаются командой `python3 -m unittest discover -s tests`.
