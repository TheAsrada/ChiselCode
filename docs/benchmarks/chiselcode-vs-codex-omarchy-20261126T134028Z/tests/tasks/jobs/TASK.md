# Задача

Реализуй `schedule(jobs)` в `solution.py`. Jobs — словарь id → список id зависимостей. Id — строки.
Считай повторяющиеся зависимости одним ребром. Если есть неизвестные id, верни
{"missing": [уникальные неизвестные id в лексикографическом порядке]} до анализа циклов.
Иначе верни {"waves": [[...], ...], "blocked": [...]}. В каждой волне одновременно идут все
доступные на её начало задачи, в лексикографическом порядке. Blocked — все задачи, которых
не было в волнах, включая участников циклов, самоссылки и транзитивных потомков, лексикографически.
Вход не меняй. Обработай тысячи задач без рекурсии и без повторного обхода всего графа в каждой волне.

Публичные проверки запускаются командой `python3 -m unittest discover -s tests`.
