# Задача

Исправь `apply_batches(stock, batches)` в `solution.py`. Stock — SKU → неотрицательный остаток.
Каждый batch — {"id": строка, "lines": [[sku, delta], ...]}. Посчитай суммарный delta на SKU
перед проверкой. Если какой-то итог отрицательный, откати весь batch и верни статус "insufficient".
При успехе примени все суммы атомарно, статус "applied". Удали затронутые SKU с нулевым итогом;
нетронутые SKU, в том числе с исходным нулём, сохраняй. Пустой batch успешен. Запоминай id только
после успеха. Каждая последующая запись с таким id имеет статус "duplicate" независимо от lines.
Верни {"stock": итоговый словарь, "statuses": список статусов в порядке входа}. Входы не меняй.

Публичные проверки запускаются командой `python3 -m unittest discover -s tests`.
