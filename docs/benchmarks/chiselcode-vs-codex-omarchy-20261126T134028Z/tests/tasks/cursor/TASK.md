# Задача

Реализуй `page(rows, limit, after, team)` в `solution.py`. Строка имеет уникальный строковый id,
целочисленный score, строковый team и может иметь другие поля. Сначала отфильтруй team
(`None` означает все команды). Сортировка — score по убыванию, затем id лексикографически.
After — null либо [score, id] последней виденной записи. При заданном after бери строго те
записи, которые шли бы за ним в этой сортировке, даже если якорь отсутствует или из другой команды.
Верни {"rows": первые limit строк с полями без изменений, "next": null или [score, id] последней
возвращённой строки}, курсор только если есть последующая строка. Лимит — целое от 1 до 50
включительно. Для 0 или 51 выбрасывай `ValueError`. Вход не меняй, включая порядок.

Публичные проверки запускаются командой `python3 -m unittest discover -s tests`.
