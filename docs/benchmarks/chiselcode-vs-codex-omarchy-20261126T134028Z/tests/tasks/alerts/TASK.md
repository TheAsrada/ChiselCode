# Задача

Исправь `dispatch(routes, events, cooldown)` в `solution.py`. Routes сопоставляет канал со списком
тегов, к которым он подписан. События — [timestamp, tag, message], исходный порядок нужен для равного
timestamp. Timestamp целый, cooldown — неотрицательное целое. Иди по (timestamp, исходный индекс).
Канал получает подходящее событие один раз даже при повторе тега в routes. При одинаковом событии
записывай каналы лексикографически. Пауза считается отдельно для каждой пары (канал, тег)
от последней фактической доставки. Доставляй при timestamp >= last + cooldown. Пропуск не сбрасывает
паузу, cooldown=0 разрешает повтор в то же время, отрицательное время допустимо. Возвращай
список [timestamp, channel, tag, message]. Входы не меняй.

Публичные проверки запускаются командой `python3 -m unittest discover -s tests`.
