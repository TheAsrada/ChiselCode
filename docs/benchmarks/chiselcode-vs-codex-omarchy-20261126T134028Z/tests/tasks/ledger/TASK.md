# Задача

Реализуй `post(opening, transfers)` в `solution.py`. Opening — словарь account → неотрицательная
сумма целых единиц. Перевод — [id, from, to, amount], amount положительный int, аккаунты — строки.
Обработай переводы по порядку. Если id уже успешно применён, статус "duplicate" имеет приоритет.
Иначе если любой аккаунт отсутствует, статус "unknown"; иначе если остаток from меньше amount,
статус "insufficient"; иначе статус "posted". Перевод на тот же счёт проверяет достаточность,
запоминает успешный id, оставляет остаток прежним. Неуспех не резервирует id. Для хранения используй
SQLite через `sqlite3` и временный in-memory ledger. Сохрани API `ledger_db.open_ledger(opening)`
и используй этот helper из solution.py. Этот helper создаёт схему, заполняет счета и возвращает
открытое соединение. Согласованно сохраняй балансы и факт применения перевода.
Верни {"balances": словарь всех счетов, "statuses": список статусов}. Входы не меняй.

Публичные проверки запускаются командой `python3 -m unittest discover -s tests`.
