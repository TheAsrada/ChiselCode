# Задача

Реализуй `occupancy(events, start, end)` в `solution.py`. События — [t, delta], все числа
целые. Накопленный occupancy начинается с 0 в прошлом и может быть отрицательным. Сложи все
delta в каждой точке t, их порядок не влияет. На t новое значение действует на интервале от t
до следующей точки. Верни {"area": интеграл по [start,end), "peak": максимальное значение
на интервале положительной длины, "peak_at": наиболее раннее его начало, обрезанное границей start}.
События на end игнорируются, события на start входят. Если start == end, верни
{"area":0,"peak":null,"peak_at":null}; если start > end, бросай `ValueError`. Вход не меняй.
Время не ограничено размером окна, большие разреженные интервалы обрабатывай без перебора каждой секунды.

Публичные проверки запускаются командой `python3 -m unittest discover -s tests`.
