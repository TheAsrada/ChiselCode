# Задача

Исправь `replay(lines, watermark)` в `solution.py`. Lines — список строк JSONL, индексы в
результате начинаются с 1. Пустые или целиком пробельные строки игнорируй. Событие должно
быть объектом ровно с полями seq, id, key, op и, для set, value. Seq — неотрицательное int
без bool, id и key — непустые строки. Op — "set" с любым JSON value либо "delete" без value.
Сначала валидируй: ошибка даёт [номер, "invalid"], даже ниже watermark. Из корректных пропускай
seq <= watermark, затем сортируй остальные по (seq, номер строки). Первый подходящий event id
побеждает, остальные дают [номер, "duplicate"]. Set заменяет значение, delete отсутствующего
ключа безопасен. Верни {"state": словарь, "issues": список пар по номеру строки,
"watermark": максимум исходного watermark и seq всех применённых событий}. Вход не меняй.

Публичные проверки запускаются командой `python3 -m unittest discover -s tests`.
