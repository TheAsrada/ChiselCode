# Установка и обновление

[Документация](README.md) · [Главная](../README.md)

## Готовые установщики

Скачивайте пакеты из [GitHub Releases](https://github.com/TheAsrada/ChiselCode/releases/latest). Замените `<версия>` в примерах на номер скачанного релиза. Workflow публикует установщики; отдельные standalone-бинарники в нём не загружаются.

| Система | Файл | Куда устанавливается программа |
| --- | --- | --- |
| Windows x64 | `ChiselCode-Setup-<версия>.exe` | `%LOCALAPPDATA%\ChiselCode` |
| macOS Apple Silicon | `ChiselCode-Setup-<версия>-macos-arm64.pkg` | `/usr/local/bin/chisel` |
| macOS Intel | `ChiselCode-Setup-<версия>-macos-x64.pkg` | `/usr/local/bin/chisel` |
| Debian/Ubuntu x64 | `ChiselCode-Setup-<версия>-linux-amd64.deb` | `/usr/bin/chisel` |

### Windows

Запустите EXE. Установка не требует прав администратора, добавляет `chisel` в пользовательский PATH и создаёт ярлык в меню «Пуск». Ярлык рабочего стола — дополнительный компонент. После установки откройте **новый** PowerShell и выполните `chisel`.

Для неподписанного EXE Windows может показать SmartScreen. Проверьте источник файла и название релиза перед запуском.

### macOS

Выберите пакет под свой процессор и откройте его системным установщиком. Если система блокирует неподписанный пакет, проверьте источник и используйте системные настройки разрешения запуска. После установки выполните `chisel` в терминале.

### Debian / Ubuntu

Из папки со скачанным пакетом:

```bash
sudo apt install ./ChiselCode-Setup-<версия>-linux-amd64.deb
chisel
```

Для других дистрибутивов и архитектур готовый установщик этим workflow не создаётся; используйте [сборку из исходников](development.md).

## Внешние инструменты

Bun не нужен для запуска скомпилированной программы из установщика. При этом `grep`-инструмент агента вызывает **ripgrep (`rg`)**, а Git-инструменты — **Git**. Они должны быть доступны в PATH; установщики проекта их не включают.

```bash
chisel --version
rg --version
git --version
```

## Обновление

| Способ | Поведение |
| --- | --- |
| `chisel update` | Проверить последнюю версию и показать ссылку на установщик |
| `chisel update --json` | Получить результат проверки в JSON, без установки |
| `/update` в чате | Проверить обновление; установленная Windows-версия может запустить тихую установку после подтверждения |
| macOS/Linux или запуск из исходников | Использовать предложенную ручную установку |

Не закрывайте терминал до завершения подтверждённого обновления. Пользовательские навыки и сессии хранятся отдельно от заменяемых встроенных навыков.

## Удаление

- Windows: используйте установленный деинсталлятор приложения.
- Debian/Ubuntu: `sudo apt remove chiselcode`.
- macOS: `sudo rm /usr/local/bin/chisel` удаляет исполняемый файл. Пакет также устанавливает встроенные навыки в `/usr/local/bin/skills/bundled`; удаляйте их только после проверки, что они относятся к ChiselCode.

Пользовательские сессии, конфигурация и ключи могут остаться после удаления программы. Их расположение описано в [конфигурации](configuration.md); удаление этих данных необратимо.

Далее: [первый запуск](getting-started.md).
