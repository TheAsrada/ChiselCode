# Интерактивный режим

[Документация](README.md) · [Главная](../README.md)

Интерактивный режим работает как в привычных агентах: обычный текст отправляется помощнику, а короткие команды начинаются с `/`. Начните вводить `/` — появится список с подсказками, Tab или Enter дополняет выбранную команду.

| Команда | Что делает |
| --- | --- |
| `/help` | показать список команд |
| `/clear` | сохранить текущий разговор, создать новый и очистить экран, оставив шапку |
| `/sessions` | открыть список разговоров текущего проекта |
| `/resume` | выбрать и продолжить сохранённый разговор |
| `/cwd <путь>` | сменить папку проекта (можно путь к файлу); без аргументов — показать текущую |
| `/settings` | меню смены сервиса, модели и адреса API |
| `/model` | быстро сменить модель для текущего сеанса |
| `/skills` | скиллы: выбрать и задействовать для сессии |
| `/status` | показать сервис, модель, папку проекта и готовность ключа |
| `/update` | проверить обновление; способ установки зависит от платформы ([подробнее](installation.md)) |
| `/doctor` | проверить настройку без показа ключей |
| `/exit` | закрыть ChiselCode |

## Клавиши и прокрутка

- **Enter** — отправить запрос (во время работы агента — встать в очередь);
- **Shift+Enter** — перенос строки для многострочной задачи;
- **↑ / ↓** — история отправленных запросов;
- **← / →** — перемещение по строке;
- **PgUp / PgDn** — скролл ленты на пол-экрана, **Ctrl+U / Ctrl+D** — ±10 строк, **Home / End** — верх / возврат к вводу;
- колесо мыши — скролл (скорость `CHISEL_SCROLL_SPEED` 1..20, по умолчанию 3; **Shift+колесо** — рывок на пол-экрана), нативное выделение текста при захваченной мыши — через **Shift**;
- **Ctrl+O** — транскрипт: `j/k`, `g/G`, `{`/`}` по промптам, `/` + `n`/`N` поиск, `q` — назад;
- скролл идёт по визуальным строкам, включая длинные ответы и блоки кода; просмотр истории не сдвигается при новых ответах, **End** возвращает слежение за последним сообщением;
- стартовая шапка — начало истории, ввод и статус остаются внизу полноэкранного окна;
- полноэкранный режим включён по умолчанию, в том числе при запуске из Windows-ярлыка или cmd; прокрутка останавливается на последнем сообщении, пустую область ниже листать нельзя;
- `CHISEL_ALT_SCREEN=0` или `CHISEL_NO_ALT_SCREEN=1` включает классический режим с нативным scrollback вместо закреплённого ввода; `CHISEL_NO_MOUSE=1` или `CHISEL_DISABLE_MOUSE=1` отключает захват мыши;
- при запросе на изменение файла или команды нажмите **y** (разрешить) или **n**/**Esc** (отклонить).

Настройки сохраняются локально. Мастер скрывает ввод ключа, а `/status` и `/doctor` показывают его готовность без значения. Не публикуйте необработанные сообщения стороннего API без проверки на секреты.
