# Интерактивный режим

[Документация](README.md) · [Главная](../README.md)

Интерактивный режим работает как в привычных агентах: обычный текст отправляется помощнику, а короткие команды начинаются с `/`. Начните вводить `/` — появится список с подсказками, Tab или Enter дополняет выбранную команду.

| Команда | Что делает |
| --- | --- |
| `/help` | показать список команд |
| `/clear` или `/new` | открыть новую вкладку, сохранив текущий разговор |
| `/home` | перейти на главную |
| `/sessions` | открыть список разговоров текущего проекта |
| `/resume` | выбрать и продолжить сохранённый разговор |
| `/cwd <путь>` | сменить папку проекта (можно путь к файлу); без аргументов — показать текущую |
| `/settings` | popup подключения, профилей и оформления |
| `/model` | быстро сменить модель для текущего сеанса |
| `/skills` | popup библиотеки: поиск, выбор для задачи, инструкции и отдельное закрепление |
| `/status` | показать сервис, модель, папку проекта и готовность ключа |
| `/update` | проверить обновление; способ установки зависит от платформы ([подробнее](installation.md)) |
| `/doctor` | проверить настройку без показа ключей |
| `/exit` | закрыть ChiselCode |

## Главная и вкладки

`chisel` открывает стартовый экран с логотипом `<i>ChiselCode` в шрифте Coder Mini и полем ввода сразу под ним. Внизу показаны папка проекта и версия. На небольшом терминале используется текстовая подпись. История доступна через `/sessions`, настройки — через `/settings`, темы — в разделе «Оформление» настроек; кнопок быстрых действий и недавних разговоров на стартовом экране нет.

Первая отправленная задача создаёт вкладку разговора; до этого строка вкладок скрыта. Сессия сохраняется после выполнения запроса. «+» сразу за вкладками открывает стартовый экран для следующей задачи и не создаёт пустую вкладку. У стартового экрана нет собственной вкладки. `/home` или Ctrl+G возвращает к нему. Вкладки имеют контур, выделение активного разговора и собственное закрытие «×». При недостатке места видна активная вкладка и соседние, а стрелки ‹/› позволяют добраться до остальных. В разговоре поле ввода остаётся снизу.

Черновик, история ввода, положение ленты и ответы принадлежат своей вкладке. Во время ответа можно перейти в другую вкладку; новые запросы выполняются по очереди и возвращают результат в исходную вкладку. Точка ● отмечает выполняющийся запрос или ожидание очереди. Активный запрос нужно завершить перед закрытием его вкладки.

«×» закрывает свою вкладку, Ctrl+W — выбранную. Сохранённая сессия остаётся в истории; открытие её через `/sessions` выбирает уже открытую вкладку либо создаёт новую. После закрытия последней вкладки открывается стартовый экран. Открытые вкладки и неотправленные черновики действуют до выхода из приложения; сохранённые разговоры доступны после перезапуска.

`/cwd <путь>` выбирает проект на главной. Уже открытые вкладки сохраняют свои папки и разговоры.

## Окно настроек

`/settings` открывает popup в том же стиле, что и библиотека скиллов: затемнённый фон, рамка, поиск, подсказки и кнопки. Разговор продолжает обновляться; черновик и курсор остаются на месте. Мышь выбирает строки и действия, Tab переключает «Подключение» и «Оформление».

В «Подключении» ↑/↓ и Enter открывают сервис, модель, API-ключ, адрес API (для совместимых сервисов) или профиль. Сервисы, модели и профили можно искать; PgUp/PgDn перемещают выбор по странице. Модель можно ввести вручную даже при медленном или недоступном API. Поля используют обычное редактирование с курсором; ключ отображается точками, включая выделение. Enter подтверждает поле, Esc отменяет его черновик. «Проверить» / Ctrl+R проверяет подключение; «Сохранить» / Ctrl+S записывает изменения и закрывает окно. Esc или щелчок снаружи отменяет несохранённые изменения. Во время проверки Esc закрывает окно без ожидания сети.

В «Оформлении» стрелки и мышь показывают тему во всём интерфейсе. Образец разговора и цветовые образцы помогают выбрать. «Применить тему», Enter или Ctrl+S сохраняют выбор; Esc возвращает последнюю сохранённую тему. Сохранение темы не записывает черновик подключения. При ошибке записи окно показывает сообщение и остаётся открытым.

На первом запуске `chisel` и `chisel setup` используют это же окно; подключение нужно сохранить перед началом разговора. Применение темы не завершает настройку подключения.

## Клавиши и прокрутка

- **Enter** отправляет запрос; **Shift+Enter** добавляет строку, если терминал передаёт сочетание. Многострочная вставка не отправляет запрос сама.
- **Alt+N** или **Ctrl+Shift+N** — стартовый экран для нового разговора; **Alt+← / Alt+→** или **Ctrl+Tab / Ctrl+Shift+Tab** — переключение существующих вкладок; **Ctrl+G** — стартовый экран; **Ctrl+W** — закрыть вкладку. Ctrl+Tab и Ctrl+Shift+N требуют поддержки сочетаний терминалом; мышь и команды работают независимо от неё.
- **Esc** возвращает из разговора на главную после закрытия панели или просмотра; на главной завершает приложение.
- **Ctrl+P / Ctrl+N** переключают историю отправленных запросов и сохраняют черновик.
- **Ctrl+,** открывает настройки в терминалах с поддержкой сочетания; **Ctrl+T** открывает «Оформление». Команда `/settings` работает во всех терминалах.
- **Ctrl+S** открывает библиотеку скиллов, сохраняя черновик задачи; `/skills` открывает её командой.
- **Ctrl+B** открывает или закрывает контекст проекта; **Esc** возвращает фокус. На широком экране контекст виден справа. `/sidebar auto|show|hide` управляет режимом панели.
- **Tab** переключает фокус между вводом, лентой и контекстом. **PgUp / PgDn** листают историю, **End** возвращает к последним сообщениям; колесо работает в ленте.
- **Ctrl+D** раскрывает diff в ленте, если нет пустого редактора; **Ctrl+C** завершает сеанс. В подтверждении **y** или **н** разрешают действие, **n**, **т** или **Esc** отклоняют.
- `CHISEL_ALT_SCREEN=0` или `CHISEL_NO_ALT_SCREEN=1` включает режим split-footer с нативной прокруткой завершённых сообщений над редактором. По умолчанию используется alternate screen.

Настройки сохраняются локально. Мастер скрывает ввод ключа, а `/status` и `/doctor` показывают его готовность без значения. Не публикуйте необработанные сообщения стороннего API без проверки на секреты.

См. также: [сессии](sessions.md), [навыки](skills.md), [CLI](cli.md).

## Profiles в settings

Провайдеры выбираются поиском из Registry, включая custom manifests. «Профиль» выбирает существующий аккаунт; «Новый профиль» создаёт независимый ID, credential reference, модель и endpoint. Смена provider сбрасывает несохранённый ключ. Сохранение меняет профиль активной вкладки и default для новых; остальные исторические вкладки сохраняют свои session profiles. Unknown provider history читается, но новый запрос требует доступный profile.
