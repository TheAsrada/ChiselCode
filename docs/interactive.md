# Интерактивный режим

[Документация](README.md) · [Главная](../README.md)

Интерактивный режим работает как в привычных агентах: обычный текст отправляется помощнику, а короткие команды начинаются с `/`. Начните вводить `/` — появится список с подсказками, Tab или Enter дополняет выбранную команду.

| Команда | Что делает |
| --- | --- |
| `/clear` | открыть черновик на главной; вкладка создаётся после отправки, текущий разговор сохраняется |
| `/compact` | сжать старую историю текущего разговора без нового ответа агента; текущий запрос и незавершённые вызовы инструментов сохраняются |
| `/resume` | найти и продолжить разговор из любого проекта; работает и без выбранной папки |
| `/cwd <путь>` | выбрать проект на главной (можно путь к файлу); без аргументов — открыть окно выбора папки |
| `/settings` | сгруппированные настройки с поиском: подключение, оформление, разрешения, LSP, MCP, Web, скиллы |
| `/model` | быстро сменить модель для текущего сеанса |
| `/plan` | перейти в Plan для изучения проекта и подготовки плана |
| `/build` | перейти в Build для выполнения изменений |
| `/permissions` | открыть выбор Manual / Accept edits / Dont ask / Bypass; `/permissions <ID>` выбирает режим |
| `/skills` | popup библиотеки: поиск, выбор для задачи, инструкции и отдельное закрепление |
| `/btw <вопрос>` | получить отдельный побочный ответ |
| `/worktree` | открыть графический менеджер рабочих копий |
| `/mcp` | центр внешних инструментов: серверы, подключение, разрешения, trust и диагностика |
| `/update` | проверить обновление; способ установки зависит от платформы ([подробнее](installation.md)) |
| `/exit` | закрыть ChiselCode |

Команды `/home` и `/sessions` удалены. Возвращайтесь на главную через Ctrl+G, открывайте историю через `/resume`.

## Главная и вкладки

В текущих исходниках главная может работать без проекта. `chisel --launcher` открывает её явно; запуск из служебной папки без задачи также не выбирает эту папку проектом. Из обычного терминала `chisel` сохраняет выбор текущего каталога. Внизу главной рядом с папкой проекта находится компактная кнопка `/cwd`: она открывает то же окно с путём, навигацией и недавними проектами, что и команда `/cwd`. Между логотипом и полем задачи нет отдельного блока выбора папки. Первый Enter без проекта открывает выбор; после выбора отправьте сохранённый текст отдельным Enter.

Без проекта доступны модель, режимы, глобальные настройки, библиотека навыков, обновления и просмотр истории. Проектные команды, конфигурация, инструкции, расширения и модельный запрос ждут выбора допустимой папки. Строка «Проект не выбран» внизу главной отличается от состояния выбранной папки без Git. В узком окне версия скрывается, чтобы оставить место папке и `/cwd`.

С версии 0.6.41 команды `/status` и `/doctor` удалены. Модель и подключение доступны в `/settings`, папка проекта — внизу экрана, статусы сервисов — по F9. Успешные служебные уведомления на главной не показываются. Ошибки команд открываются в отдельном прокручиваемом окне. Enter, Esc или Ctrl+C закрывают его и возвращают ввод; после закрытия текст под полем не остаётся и вкладка разговора не создаётся.

В `/mcp` стрелки и Enter выбирают сервер и действия, PgUp/PgDn листают длинные списки, Esc возвращает назад. Добавление предлагает URL, локальную команду или расширенные настройки; тест и обнаруженные tools показываются до сохранения. Действие «Проверить подключение» проверяет заполненную форму, Ctrl+S сохраняет проверенный сервер или категории разрешений. Ctrl+C останавливает текущую проверку. Для сервера доступны состояние, протокол, инструменты, их индивидуальные правила, диагностика, безопасный журнал и включение/отключение. Команды проекта требуют отдельного доверия с показом точной команды. [Руководство MCP](mcp.md).

`chisel` открывает стартовый экран с графическим логотипом Coder Mini и полем ввода сразу под ним. Внизу показаны папка проекта и версия. На небольшом терминале используется текстовая подпись. История доступна через `/resume`, настройки — через `/settings`, темы — в разделе «Оформление» настроек; с версии 0.6.41 на широком и высоком экране доступны переходы к модели, истории и настройкам.

Первая отправленная задача создаёт вкладку разговора; до этого строка вкладок скрыта. Сессия сохраняется во время исполнения и после завершения запроса. «+» сразу за вкладками открывает стартовый экран для следующей задачи и не создаёт пустую вкладку. У стартового экрана нет собственной вкладки. Ctrl+G возвращает к нему. В текущих исходниках активная вкладка выделена нижней линией; у каждой вкладки есть собственное закрытие «x». При недостатке места видна активная вкладка и соседние, а стрелки < / > позволяют добраться до остальных. В разговоре поле ввода остаётся снизу.

Черновик, история ввода, положение ленты и ответы принадлежат своей вкладке. Во время ответа можно перейти в другую вкладку; новые запросы выполняются по очереди и возвращают результат в исходную вкладку. Индикатор во вкладке отмечает выполняющийся запрос или ожидание очереди. Активный запрос нужно завершить перед закрытием его вкладки.

«x» закрывает свою вкладку, Ctrl+W — выбранную. Сохранённая сессия остаётся в истории; открытие её через `/resume` выбирает уже открытую вкладку либо создаёт новую. После закрытия последней вкладки открывается стартовый экран. Открытые вкладки действуют до выхода из приложения. Неотправленные черновики сохраняются отдельно и восстанавливаются после перезапуска; сохранённые разговоры доступны в истории.

`/cwd <путь>` выбирает проект на главной. Уже открытые вкладки сохраняют свои папки и разговоры.

Esc в выборе папки отменяет только текущее открытие и возвращает редактор без окна ошибки. Если истекло время открытия, приложение сообщает об этом отдельно; поздний ответ не меняет выбранный проект.

## Дополнительные команды

Команды встроенных расширений видны в обычных подсказках уже на главной. Tab или Enter вставляет выбранную команду; выполнение начинается только при отправке. Неизвестная команда не отправляется модели. Имена чувствительны к регистру, аргументы передаются буквально, без выполнения shell-кода.

Обычные команды выполняются по очереди с задачами своей вкладки, используя папку, режим и разрешения на момент отправки. Локальным операциям не нужен API-ключ модели. Изменения требуют тех же разрешений, что и действия агента. `/btw` получает отдельный текстовый ответ параллельно основной работе; его поведение описано ниже.

## Боковая панель

В текущих исходниках служебных кнопок «Фон», «Агенты», LSP и «Ещё» под вводом нет. F7 открывает агентов, F8 — фоновые задачи, F9 — состояния сервисов; тот же список доступен через **Меню → Состояние сервисов**. Все сочетания собраны в [горячих клавишах](keybindings.md).

При каждом входе в новую или сохранённую беседу панель сама появляется справа, если хватает ширины. Закрытие через Ctrl+B или `x` относится только к текущему экрану: переход в другую беседу, возврат из главной и новый запуск восстанавливают автоматическое размещение. Панель не забирает фокус у ввода. На главной она скрыта до явного открытия. В текущих исходниках на просторной главной доступны отдельные переходы в модель, историю и настройки рядом с вводом; [оформление и анимации](themes.md#анимации-и-плавность) настраиваются пользователем.

Справа находятся три постоянные вкладки: **Меню**, **Контекст**, **Агенты**. Выбранный раздел выделен цветом, а `>` отмечает фокус клавиатуры. Tab достигает полосы «Меню / Контекст / Агенты», ←/→ выбирают раздел, следующий Tab переводит фокус в содержимое. Эти клавиши продолжают вводить текст в редакторе сообщения. `F7` открывает агентов. `Esc` возвращает фокус в чат, `Ctrl+B` переключает видимость, кнопка `x` скрывает панель.

**Меню** открывает существующие окна истории, модели, оформления, разрешений, подключения, навыков и MCP. Доступность пунктов зависит от подключённых возможностей. ↑/↓, Home/End и PgUp/PgDn выбирают пункт; действие запускается щелчком или соответствующей командой/горячей клавишей. С версии 0.6.41 Enter или Space открывает выбранный пункт. `/` или поле поиска фильтрует действия по названию, описанию, разделу и команде. Цифры и скобки в поиске вводят текст. Enter из меню сохраняет черновик; после Esc Enter снова отправляет текст из редактора. Действия настроек сохраняют черновик и возвращают в панель после закрытия окна.

**Контекст** разделён на модель, окно контекста, расход сессии, проект, изменения Git и активность. Полоса показывает заполнение текущего окна; оценка помечена `~`. Лимит берётся из API или каталога точных ID; каталог отмечен подписью. При неизвестном лимите процента нет, а панель показывает поле `context.contextWindow` для [ручной настройки](configuration.md#параметры-core-runtime-v2) в `.chiselrc`. ↑/↓, Home/End, PgUp/PgDn и колесо прокручивают содержимое. Позиция сохраняется при переключении вкладок панели.

**Агенты** показывают дерево задач, состояние и текущий шаг; выбранный помощник имеет отдельный блок действий внизу. Enter или «Открыть» показывают результат, `S` или «Стоп» останавливают выбранного работающего помощника. Ctrl+C в панели не отменяет основную задачу. Подробнее: [помощники](subagents.md).

От 120 колонок панель находится рядом с чатом. При ширине 80–119 по Ctrl+B или F7 она открывается справа поверх него; в более узком окне занимает всю ширину. Вкладки и действия доступны даже в 24×8. Оформление использует текущую тему и графические элементы OpenTUI.

## Окно настроек

`/model` и нажатие на название модели под полем ввода открывают отдельный popup. Поиск работает по имени и точному ID; > отмечает текущую модель. ↑/↓, PgUp/PgDn и колесо перемещают выделение; Enter, «Выбрать» или щелчок по строке сразу применяют модель и закрывают окно. В широком терминале справа показаны ID и лимиты контекста/ответа, если провайдер их сообщает.

Tab/Shift+Tab обходят подразделы, поиск, список и действия. На полосе «Модели / Профили» ←/→ меняют подраздел. Выбор профиля пока меняет только список: подключение применяется после выбора модели. «Ввести ID» открывает ручной ввод; «Обновить каталог» перечитывает модели. Оба действия доступны через Tab, стрелки и Enter. Ручной ID и уже известная модель доступны во время загрузки и при ошибке API. Esc из ручного ввода возвращает список; Esc в списке или щелчок снаружи отменяет выбор. «Настройки» открывает подключение для добавления профиля или ключа.

Быстрый выбор относится к следующему сообщению текущей сессии. Он сохраняется с разговором; «+» и `/clear` наследуют выбор активной вкладки. Уже отправленный запрос, включая очередь, сохраняет свои модель, профиль и адрес API. Название под вводом показывает следующий выбор, даже если старый запрос ещё работает. Черновик и положение курсора сохраняются. Значения по умолчанию для запуска приложения меняются в `/settings`.

`/settings` открывает окно с группами «Модель и подключение», «Оформление», «Разрешения», «Инструменты». В терминале от 100×26 навигация находится в отдельной левой панели с разделителем; выбранный раздел остаётся выделенным при работе с полями справа. В меньшем окне сначала показан каталог, Enter открывает раздел, Esc возвращает в каталог. Настройки сохраняют текущую вкладку, черновик сообщения и курсор. Действия относятся к проекту, выбранному при открытии окна.

Ctrl+F открывает локальный поиск по названиям разделов и полей: «ключ/api», «theme», «lsp», «анализ кода», «typescript», «mcp», «web». Enter открывает найденный раздел или поле. Поиск не использует модель, сеть, ключи или значения конфига. Esc сначала очищает query, затем возвращается из поля/раздела и закрывает чистое окно. Tab / Shift+Tab переключают зоны фокуса; стрелки и PgUp/PgDn выбирают строки. В открытом поле стрелки принадлежат native input, включая cursor, selection, paste и undo. Выбранный пункт сам ничего не сохраняет и не запускает.

В «Подключении» ↑/↓ и Enter открывают сервис, модель, API-ключ, адрес API или профиль. Сервисы, модели и профили можно искать; модель доступна для ручного ввода при недоступном API. Ключ остаётся маской, включая native buffer и выделение. Enter принимает значение в draft, Esc отменяет ввод поля. Действие «Проверить подключение» проверяет параметры. Ctrl+S или кнопка «Сохранить» сохраняют только текущую форму и оставляют её открытой. Первый setup завершается лишь после сохранённого подключения.

Connection, Web и LSP drafts сохраняются при переходе между разделами. При закрытии с изменениями доступны «Остаться», «Сохранить текущую форму», «Сбросить все изменения»; ↑/↓, Enter или мышь выбирают действие. Сохранение текущей формы не сохраняет drafts других разделов. В «Оформлении» выбор темы сразу даёт preview; навигация сохраняет preview, явное применение записывает тему, сброс возвращает сохранённую тему. Ошибка сохранения оставляет draft. MCP и «Навыки» теперь открываются внутри Settings: список, подробности и управление остаются в выбранном разделе. MCP сохраняет незавершённую форму при переходах; закрепление навыков действует сразу для исходной беседы. В «Навыках» Tab достигает полосы «Библиотека / Закрепление» и именованных действий; стрелки выбирают подраздел или операцию. «Инструкции» открывает текст, «Обновить каталог» перечитывает навыки. Выбор для задачи, создание и изменение сначала закрывают настройки с обычной проверкой несохранённых форм, затем готовят черновик без отправки. Команды `/mcp` и `/skills` по-прежнему открывают отдельные окна. Это изменение находится в 0.6.34.

Интерактивный интерфейс использует единое графическое оформление OpenTUI: логотип Coder Mini, округлые рамки и ползунок прокрутки. Переключатель «Графика» удалён в 0.6.34. Старое значение `ui.unicodeDecorations: false` игнорируется; отдельного ASCII-оформления нет. Нужен моноширинный шрифт с поддержкой Unicode.

В «Разрешениях» переключатель «Разрешить Bypass» сразу сохраняет доступность режима. После включения Bypass нужно выбрать отдельно через `/permissions` или F4. Подробнее: [режимы разрешений](permissions.md).

На первом запуске `chisel` и `chisel setup` используют это же окно; подключение нужно сохранить перед началом разговора. Применение темы не завершает настройку подключения.

## Расширения в настройках

Выберите «Расширения» в `/settings`. Поиск и фильтр помогают найти пакет; нажатие или Enter открывает карточку с описанием, состоянием и именованными действиями. Стрелки и Enter выбирают действие, Esc возвращает назад. Технические сведения раскрываются отдельно. [Установка, доверие и управление расширениями](extensions.md#настройки--расширения).

## Анализ кода (LSP)

1. Откройте **Панель → Меню → Анализ кода · LSP**. Строка LSP в F9 и `/settings` → Инструменты → Анализ кода открывают то же меню. При выбранной папке начальная область — **Этот проект**; без папки доступны **Все проекты** и «Выбрать проект».
2. Строка **Анализ кода: Включён / Выключен** сохраняется сразу. Отключение запрещает новые запросы и закрывает серверы выбранной области. Включение оставляет их ждать следующего запроса. Общий запрет нельзя отменить проектным переключателем: он переводит к общим настройкам с объяснением.
3. По умолчанию видны использованные серверы, ручные записи и исключения. «Все поддерживаемые серверы» раскрывает каталог; Ctrl+F в содержимом LSP ищет по названию и языку. Для поиска разделов Settings переключите фокус из содержимого через Shift+Tab и нажмите Ctrl+F либо выберите верхнее поле мышью. Enter или нажатие открывают карточку, Space либо кнопка переключателя меняют разрешение выбранного сервера. «Ждёт запроса» отличается от «Работает»: включение само по себе ничего не запускает.
4. В карточке показаны состояния всех корней проекта, причины отказа и диагностика с файлом, строкой и свежестью. «Запустить сейчас» / «Перезапустить» используют обычную очередь инструментов и разрешения Build. Модель и API-ключ не нужны. В Plan явный запуск ограничен, автоматическая навигация чтения остаётся доступна. Перезапуск и выключение сервера затрагивают его экземпляры во всех вкладках этого workspace.
5. «Стратегия» явно предлагает Auto или «Своя настройка»; у проекта есть наследование и выбор ручного сервера. Ручная форма сохраняется отдельно через «Сохранить» / Ctrl+S: executable, argv по одному на строку, языки, расширения и дополнительные JSON-параметры. «Проверить пути» ничего не выполняет. Точное доверие к папке выдаётся отдельным действием; включение сервера его не выдаёт. [Версии и ограничения запуска](configuration.md#анализ-кода-lsp).

↑/↓ выбирают строки, PgUp/PgDn листают список, Tab / Shift+Tab меняют области фокуса. В штатных полях ввод, Space и стрелки принадлежат редактированию. Esc возвращает на предыдущий уровень; форма остаётся черновиком до явного сохранения или сброса. Поиск, переход в другой раздел и изменение размера сохраняют черновик. «Обновить данные» обновляет revisions после конфликта, сохраняя поля формы для проверки перед записью. Неуспешное сохранение не показывается как применённое выключение; при сохранённой настройке и неподтверждённом завершении процесса доступно «Повторить завершение процессов».

Auto выбирает язык и ближайший разрешённый корень проекта. TypeScript/JavaScript входят в приложение и работают без отдельного Node или доверия каждому проекту. Для других языков первый запрос может скачать закреплённый сервер и SDK. Просмотр меню, поиск, сохранение и возврат к наследованию ничего не устанавливают и не запускают. Индивидуальное выключение Python оставляет TypeScript и другие разрешённые языки доступными.

Диагностика различает **current**, **observed**, **pending**, **stale** и **unavailable**. TypeScript присылает результаты без document version, поэтому даже пустой **observed** набор не подтверждает отсутствие ошибок. Только пустой **current** результат получает соответствующую подпись. Анализ ограничен отслеживаемыми документами; используйте релевантные тесты и компилятор. LSP не выполняет rename, formatting, code actions или workspace edits.

Пользовательские `/lsp-status` и `/lsp-restart` удалены вместе с подсказками. Шесть инструментов LSP для агента сохранены; `/help` не возвращён. [Подробная настройка и наследование](configuration.md#анализ-кода-lsp).

## Клавиши и прокрутка

Откройте **[Горячие клавиши](keybindings.md)**: таблицы для чата, вкладок, ленты, боковой панели, помощников, фоновых задач и окон. Справка учитывает фокус и отдельные значения сочетаний в каждом окне.

Обычные вызовы инструментов собраны в раскрываемые **«Действия агента»**, загрузки `load_skill` — в отдельные **«Навыки»**. Внутри доступны состояния, команды, пути и сохранённые результаты. Ошибки видны в закрытом блоке; diff, подтверждения, помощники и фоновые задачи остаются отдельными. [Сводки и длинный вывод](agent-actions.md).

`CHISEL_ALT_SCREEN=0` или `CHISEL_NO_ALT_SCREEN=1` включает режим split-footer с нативной прокруткой завершённых сообщений над редактором. По умолчанию используется alternate screen.

Разные вкладки работают параллельно. Следующие сообщения одной вкладки выполняются последовательно с выбранными при отправке моделью, режимом и разрешениями. Подтверждение ждёт в своей вкладке, даже если открыта другая; вкладка отмечается `?`. Ctrl+Tab или Alt+←/→ позволяют переключиться прямо из подтверждения. Изменяющие операции в общем workspace синхронизируются; устаревшие правки требуют нового чтения файла.

Панель «Контекст» показывает размер окна выбранной модели, текущие занятые токены, процент и цветную полоску заполнения. В расчёт входят инструкции, схемы инструментов и история, которая действительно отправляется модели; после сжатия истории заполнение уменьшается. `~` означает оценку, а «каталог» или «настройки» у окна указывают резервный источник его размера. Если размер неизвестен, процент не показывается. «Расход сессии» — отдельная сумма оплаченных input/output, она может превышать окно модели.

Настройки сохраняются локально. Мастер скрывает ввод ключа, готовность ключа видна в настройках подключения без показа значения. Не публикуйте необработанные сообщения стороннего API без проверки на секреты.

См. также: [сессии](sessions.md), [навыки](skills.md), [CLI](cli.md).

## Поиск в интернете в настройках

Поиск и открытие публичных страниц по умолчанию стоят в «Разрешено» и не вызывают approval popup. «Спрашивать» включает подтверждения отдельно для операции, «Запретить» отключает её. Сохранённые явные Ask/Deny сохраняются; user/project deny и SSRF имеют приоритет во всех режимах, включая Allow и Bypass.

В `/settings` → Web можно включить/отключить native Web, выбрать Ask/Allow/Deny отдельно для поиска и открытия страниц и переключить режим Авто / Exa / Parallel / Brave. По умолчанию стоит **Авто**: Exa → Parallel, сохранённый ключ Brave добавляет его первым. При недоступности сервис заменяется следующим разрешённым, без ручного выбора. Exa и Parallel работают без отдельного API-ключа; поле ключа появляется при выборе Brave. Web имеет отдельный draft: изменения сохраняются кнопкой «Сохранить», Ctrl+S. Показано состояние корпоративной сети: proxy, CA и mTLS без секретов. Safe browsing включён постоянно, локальные адреса заблокированы. [Настройка корпоративной сети](network.md).

В первом approval URL или поисковый запрос показан целиком; для Auto перечислены возможные сервисы и их endpoints: **Y** разрешает один раз, **A** — поиск или точный домен на текущую сессию, **N / Esc** отклоняет. Grant поиска не разрешает открытие всех найденных страниц. Во время параллельных чтений попапы появляются последовательно. Чат показывает использованный сервис, число результатов, title и final URL, большие документы доступны через artifact. Ctrl+C отменяет текущий запрос. [Подробнее](web.md).

## Профили подключения

Провайдеры выбираются поиском из Registry, включая custom manifests. «Профиль» выбирает существующий аккаунт; «Новый профиль» создаёт независимый ID, credential reference, модель и endpoint. Смена provider сбрасывает несохранённый ключ. Сохранение меняет профиль активной вкладки и default для новых; остальные исторические вкладки сохраняют свои session profiles. Unknown provider history читается, но новый запрос требует доступный profile.

## Побочный вопрос: /btw

`/btw <вопрос>` получает отдельный ответ выбранной модели, пока основная задача продолжает работать. Окно «Побочный вопрос» открывается после отправки. Esc или «Скрыть» прячет окно без отмены; F6 или «Открыть» в записи чата возвращает ответ. «Остановить ответ» отменяет только побочный запрос. Ctrl+C по-прежнему останавливает основную задачу и её очередь.

Tab и Shift+Tab перемещают фокус между текстом и действиями окна. «Новый вопрос» открывает отдельный черновик, «Копировать» копирует полученный текст. Подтверждение основной операции временно получает приоритет; ответ продолжает поступать. Смена вкладки скрывает окно, не перенаправляя запрос.

Используется ограниченная история на момент отправки. Побочный ответ не выполняет инструменты и не попадает автоматически в историю основной задачи. Сохранённые ответы открываются после возвращения к разговору без повторного запроса. Действует один активный побочный вопрос на разговор; ошибки, отмена и обрезка отмечаются явно. [Полное руководство: окно, клавиатура, сохранение и ограничения](side-questions.md).

## Изолированные рабочие копии

`/worktree` и пункт «Рабочие копии» в меню проекта открывают менеджер. Основной проект отделён от копий ChiselCode и других копий Git. Можно создать копию от сохранённого коммита, открыть её, выбрать и перенести результат через обычные разрешения, закрыть вкладку или безопасно удалить чистую копию. UUID вручную вводить не требуется.

Текстовые `/worktree create/list/open/status/diff/apply/remove` сохраняются для автоматизации; `/worktree origin` возвращает в основной проект. Конфликты и изменение результата после просмотра останавливают перенос; закрытие вкладки сохраняет файлы. Полный порядок и ограничения — в [руководстве](worktrees.md).

Ctrl+W закрывает вкладку, сохраняя папку. Ctrl+C останавливает текущую операцию и очередь, сохраняя файлы. На узком терминале боковая панель по умолчанию скрыта; поле ввода и подтверждение остаются доступны, предпросмотр прокручивается стрелками и PgUp/PgDn. [Полное руководство: создание, перенос, удаление и ограничения](worktrees.md).

## Помощники

В чате помощники отображаются карточками с поручением, моделью, состоянием и текущим шагом. **Открыть** показывает подробности задачи; прогресс обновляет ту же карточку. F7 открывает раздел **Агенты** боковой панели; Enter показывает ход работы, изменения и итог; действие «Остановить» отменяет выбранного помощника. См. [Помощники и делегирование задач](subagents.md).
