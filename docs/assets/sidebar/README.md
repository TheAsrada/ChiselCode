Архивные кадры, снятые до обновления меню в CLI 0.6.41. Текущее управление описано в [справке](../../interactive.md#боковая-панель).

Кадры получены настоящим OpenTUI 0.5.12. Одноимённые TXT содержат `captureCharFrame`, JSON — `captureSpans`; PNG экспортирован из этих spans. На этапе съёмки fixture проверял, что Enter не открывает пункт меню и не отправляет черновик, мышь открывает прежние окна, а после возврата в редактор Enter отправляет сообщение.
