# Материалы для участников проекта

[Документация](../README.md) · [Разработка](../development.md) · [Архитектура](../architecture.md)

Здесь находятся отчёты о реализации, результаты проверок и кадры настоящего интерфейса. Они относятся к указанным коммитам и версиям: исторический прогон не означает, что та же проверка выполнена для каждого следующего изменения. Пользовательские действия и ограничения описаны в справке, внутренние контракты — в архитектуре и руководстве разработчика.

| Изолированные рабочие копии | [Как пользоваться](../worktrees.md) | [Реализация, проверки и кадры интерфейса](reports/worktrees.md) |

Отдельные материалы: [совместимость OpenTUI](../opentui-compatibility.md), [терминальная матрица](../opentui-terminal-matrix.md), [проектирование просмотра изменений](../file-edit-ux.md). Команды для воспроизведения проверок находятся в [руководстве разработчика](../development.md).

Номера этапов в отчётах связывают реализацию с планом проекта. Готовность реализации, результаты проверок и факт публикации релиза указаны раздельно; планы будущих возможностей не являются описанием работающего продукта.
