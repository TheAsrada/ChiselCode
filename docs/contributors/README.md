# Материалы для участников проекта

[Документация](../README.md) · [Разработка](../development.md) · [Архитектура](../architecture.md)

Здесь находятся отчёты о реализации, результаты проверок и кадры настоящего интерфейса. Они относятся к указанным коммитам и версиям: исторический прогон не означает, что та же проверка выполнена для каждого следующего изменения. Пользовательские действия и ограничения описаны в справке, внутренние контракты — в архитектуре и руководстве разработчика.

Правила агента находятся в [AGENTS.md](../../AGENTS.md). [Синхронизация CLI и Desktop](desktop-sync.md) применяется только при отдельном явном поручении по концепту Desktop; обычная работа над CLI её не требует.

[Порядок проверок](testing.md) объясняет выбор локальных тестов, параллельную CI, сохранённое покрытие и проверку release source без лишних повторов.

[Выпуск CLI 0.6.39](reports/release-0.6.39.md): Native CI точного source, опубликованные установщики, npm-пакет и контрольные суммы.

[Выпуск CLI 0.6.38](reports/release-0.6.38.md): интерактивные расширения, события агента, Native CI и проверка пяти опубликованных файлов.

[Выпуск CLI 0.6.37](reports/release-0.6.37.md): допуск коммита, Native CI и проверка опубликованных пакетов с исправлением потоковых ответов.

[Разбор сохранённых разговоров и снятие квот помощников](reports/conversation-diagnostics.md) содержит проверку каждого приложенного файла, подтверждённые причины и кадры OpenTUI.

[Изменения CI и измерения времени](reports/ci-efficiency.md) содержат результаты конкретных прогонов и ограничения сравнения.

[Поиск Web без внутренних квот](reports/web-search.md) описывает причины прежних отказов, совместимость настроек и проверки настоящих поисковых сервисов.

[Разбор `web_fetch` по пяти разговорам](reports/web-fetch-diagnostics.md): отказы сайтов, ограниченный статический HTML, UTF-8 в превью и проверки исправлений.

[Разбор отказов провайдера и ошибок инструментов](reports/provider-client-diagnostics.md): полный разговор, HTTP 400 с `[DONE]`, исходящие Chat Completions запросы, границы Git и продолжение после отказа.

[Чистая главная и автоматическая панель](reports/clean-navigation.md): F7/F8/F9, совместимость настроек, проверки и настоящие кадры обеих тем.
