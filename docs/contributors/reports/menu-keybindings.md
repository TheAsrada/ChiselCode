# Навигация меню и именованные действия

[Материалы участников](../README.md) · [План](../plans/menu-keybindings.md) · [Контракт фокуса](../../architecture/menu-navigation.md) · [Клавиши](../../keybindings.md)

Изменение для CLI 0.6.49 реализует план меню на базе `977c4a4cb0026d138b45b78318c2e517be996377` (0.6.48). Уже реализованное меню LSP сохранено. React и OpenTUI 0.5.12 не обновлялись.

## Поведение

Модели, навыки и история обходятся через Tab: подразделы, поиск, список, действия. Ручной ID и обновление доступны при незавершённом каталоге; инструкции навыков прокручиваются. Компактная строка позволяет выбрать каждую доступную операцию. Settings сохраняет Ctrl+F и Ctrl+S текущей формы; F2 и локальные команды разделов удалены. В боковой панели Tab достигает полосы разделов, ←/→ выбирают раздел. Рабочие копии, помощники и фон используют именованные действия; подтверждения и контроллеры операций сохранены.

Снятые сочетания не передаются чату за открытым окном. Глобальные клавиши главной, история ввода, вкладки, diff, буфер и подтверждения сохраняются. `/help` не возвращён.

## Проверки

На Windows выполнены точечные native tests моделей, навыков, истории, Settings/MCP, панели, помощников, фона и рабочих копий. Новая матрица из 17 tests в `menu-keybindings.test.tsx` проверяет именованные операции на 120×40, 80×24, 60×15 и 32×10, снятые сочетания, ввод русского ID, прокрутку инструкций, подтверждение удаления и held key после resize. Production fixtures сохраняют проверки настоящих root, разрешений, сохранения и cleanup; меняется путь к действию.

В подготовленном рабочем дереве Windows прошли `test:fast` (492 tests), typecheck, lint и build; CLI JS вернул 0.6.49. Lint завершился без ошибок, с 418 warnings и 58 infos. `docs:check` подтвердил 136 страниц и 1536 локальных ссылок без ошибок. Отдельный прогон 141 UI-проверки и последующие затронутые tests прошли; эти наборы пересекаются и не суммируются. Runtime-сценарии истории, Settings, рабочих копий, фона и обычного TUI помощников прошли. Проверка parent delegation один раз достигла существующего лимита 45 с; единственный точечный повтор прошёл за 44,4 с. Лимит и assertions не менялись.

Итоговые результаты release source, Native validation и публикации будут записаны в отчёте выпуска после их выполнения. Физические терминалы, системный clipboard и macOS Intel этим локальным renderer-прогоном не подтверждены.
