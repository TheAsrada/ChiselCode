## Допуск к выпуску

Перед созданием тега запускается Native validation на точном release source. Нужны успешные Full source на Linux и Native smoke на Linux, Windows и macOS. Результаты, source и ссылки будут записаны после завершения jobs.

## Публикация и проверка файлов

Release workflow повторно проверяет допуск точного коммита, собирает четыре установщика и npm-архив CLI/SDK. Размеры и SHA-256 опубликованных файлов, проверка скачанного DEB и установленного npm-пакета будут добавлены после публикации. Подготовка версии и успешная локальная проверка не означают, что выпуск уже опубликован.
