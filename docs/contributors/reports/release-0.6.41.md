# Выпуск CLI 0.6.41

[Материалы участников](../README.md) · [Установка](../../installation.md) · [Искра и состояния запроса](request-activity.md) · [Оформление интерфейса](interface-design.md) · [Чистая главная](home-commands.md)

Кандидат CLI 0.6.41 подготовлен 25 октября 2026 года. Публикация ещё не выполнена; текущий опубликованный выпуск — 0.6.40. В кандидат входят обновлённый композер и меню, общая система движения и настройка reduced motion, фирменная искра со статусами реальных действий и главная без служебной ленты. Slash-команды `/status` и `/doctor` удалены.

Версии `package.json`, корневого `package-lock.json` и `src/version.ts` синхронизированы. Код продукта совпадает с проверенной реализацией `95b4e36ccf94b9e8411ef179bd8e8826af1ba7a6`, кроме номера версии; предыдущие результаты сохранены в [отчёте об искре](request-activity.md#итоговая-ci). Для допуска нового тега заново проверяется точный release source; успешный прогон предыдущего коммита его не заменяет.

## Проверки release source

Результаты нового Native validation и Quick CI, точный source и созданный после проверок tag будут зафиксированы здесь после завершения. Полный source-набор выполняется один раз на Linux; Windows/macOS получают платформенные проверки и installed/compiled smoke. Публикация требует всех четырёх обязательных jobs.

## Публикация и проверка файлов

Release workflow должен подтвердить допуск точного source, собрать четыре установщика и npm-архив с SDK и опубликовать пять assets. После публикации будут проверены размеры, SHA-256, версия опубликованного Linux binary и manifest npm-пакета. Старые tags и assets не заменяются.

## Ограничения проверки

Полный source-набор на Windows/macOS не повторяется. Intel macOS package собирается, но отдельный запуск на физическом Intel Mac и ручной GUI-прогон установщиков не входят в эту проверку. Установщики не подписаны; нотариальная проверка macOS не выполняется. Скорость физического терминала и SSH не измеряется. Концепт Desktop не изменяется и не выпускается.
