# Scratch Workspace

[Документация](README.md) · [Разрешения](permissions.md) · [Фоновые задачи](background-tasks.md)

В режиме Build агент может подготовить временный скрипт или данные в Scratch Workspace. Можно попросить агента сохранить проверку во временный Python-скрипт и запустить её без изменений в проекте. Файлы хранятся в подпапке `scratch/` пользовательского каталога [ChiselCode Home](sessions.md). У каждого проекта и разговора своя папка. Если ChiselCode Home находится внутри выбранного проекта, Scratch Workspace недоступен.

## Создание и запуск

1. Агент вызывает `scratch_workspace` с `action: "write"`, именем `name: "check.py"` и исходным текстом в `content`. Повторная запись с тем же именем атомарно заменяет файл.
2. Агент вызывает `run_shell` с `scratch: true` и `command: "python3 check.py"`. На Windows подойдёт `python check.py` или `py -3 check.py`, если выбранный runtime доступен. Для JavaScript можно использовать `node check.cjs` или `bun check.cjs`. ChiselCode использует установленные команды из окружения.
3. При следующем вызове можно использовать то же имя. `list` показывает относительные имена и размеры, `read` читает текст по имени. Чтобы удалить один файл, используйте `remove` с его именем. `clear` удаляет всю папку разговора и её содержимое.

`scratch: true` выбирает рабочую папку автоматически. Опустите `cwd`, `targetWorktreeId` и фоновые параметры. Уже работающую команду можно перевести в фон через штатное действие «В фон», если политика и настройки это разрешают. Для нового запуска выполните свежий вызов `run_shell` с `scratch: true`.

Имена файлов для `write`, `read` и `remove` содержат до 80 символов. Используйте строчные латинские буквы, цифры, точку, дефис и подчёркивание. Папки и системные имена Windows в этих операциях недоступны. Текст читается и записывается как UTF-8. Один файл можно прочитать или записать размером до 1 МиБ. Перед записью и запуском проверяются суммарные 8 МиБ и 64 элемента, включая файлы и каталоги, созданные предыдущими командами. При превышении лимита удалите файлы или очистите папку.

Все действия `scratch_workspace` используют разрешение на запись, в том числе `read` и `list`, поскольку доступ может обновить срок хранения или убрать истёкшие данные. Запуск требует штатного разрешения `run_shell`. Scratch Workspace изолирует временные файлы инструментов. Сам процесс работает с правами пользователя и может обращаться к другим папкам и к сети. Лимиты Scratch Workspace проверяются при обращении к папке, а во время выполнения действуют штатные ограничения времени и захвата вывода.

## Хранение и очистка

Продолжение сессии использует прежние файлы, пока они сохраняются. Через семь суток бездействия данные становятся доступны для очистки при следующей работе ChiselCode. При удалении разговора приложение пытается сразу убрать его папку. Если команда ещё занимает её или завершение процесса не подтверждено, очистка откладывается. Отмена команды сохраняет опубликованные файлы и успевшие появиться результаты. `clear` удаляет файлы с диска, а ранее отправленный текст и вывод остаются в истории разговора.
