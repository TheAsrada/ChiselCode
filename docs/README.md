# Документация ChiselCode

[Главная](../README.md) · [Скачать релиз](https://github.com/TheAsrada/ChiselCode/releases/latest)

ChiselCode — терминальный помощник для работы с кодом. Выберите инструкцию по своей задаче. Справка описывает возможности текущей версии исходников; версию установленного приложения показывает `chisel --version`. Сведения о доступности функции в релизе указаны в её руководстве.
