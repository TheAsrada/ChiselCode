# Документация ChiselCode

[Главная](../README.md) · [Скачать релиз](https://github.com/TheAsrada/ChiselCode/releases/latest)

ChiselCode — терминальный помощник для работы с кодом. Здесь собраны инструкции для пользователей и разработчиков. Справка описывает реализацию в текущей ветке; версию установленного приложения показывает `chisel --version`.
