# Skill Creator

Помоги пользователю создать скилл для ChiselCode: папку с `SKILL.md`
(обязательно) и при необходимости `scripts/`, `references/`, `assets/`.

## Куда класть

ВСЕ новые скиллы сохраняются ТОЛЬКО в личную папку для всех проектов:

- Windows: `%LOCALAPPDATA%\ChiselCode\skills\<имя>\SKILL.md`
- macOS/Linux: `~/.local/share/chiselcode/skills/<имя>/SKILL.md`
  (или `$XDG_DATA_HOME/chiselcode/skills/<имя>/`, если задан)

Не клади скиллы в проект. Проектный `.chisel/skills/` и общий
`.agents/skills/` — только для чтения чужих скиллов.

Имя папки — это имя скилла (`deploy`). Встроенные команды (`/settings`,
`/model`, `/skills`…) перекрыть нельзя. Если скилл не должен вызываться
как команда, а только задействоваться через меню — добавь во frontmatter
`user-invocable: false`.

## Формат SKILL.md

Файл начинается с YAML-frontmatter между `---`, дальше markdown-инструкции:

```markdown
---
name: deploy
description: Деплой сервиса одной командой. Используй, когда просят задеплоить, выкатить релиз или обновить staging.
---

# Deploy

1. Проверь `git status`: дерево должно быть чистым.
2. Собери проект: ...
3. Задеплой: ...
```

Требования к полям:

- `name`: латиница в нижнем регистре, цифры, дефис; без висячих
  и двойных дефисов; максимум 64 символа; совпадает с именем папки.
- `description`: что делает скилл И когда срабатывать. Это главный
  триггер: агент читает описания всех скиллов и сам решает, какой
  открыть. Добавляй конкретные фразы пользователя («задеплой»,
  «ревью диффа»), а не только формальное описание. Максимум 1024 символа.
- Необязательные: `license`, `compatibility` (что нужно: сеть, пакеты),
  `metadata` (словарь строк), `allowed-tools` (через пробел, experimental).

## Как писать инструкции

- Императив и конкретика: шаги, команды, ожидаемый формат вывода.
- Раздел «Подводные камни» — самое ценное: типовые ошибки и как их
  избегать. Пополняй его, когда агент спотыкается.
- Держи SKILL.md короче 500 строк: длинную справку уноси
  в `references/`, повторяющийся код — в `scripts/`, шаблоны — в `assets/`.
  Из SKILL.md ссылайся относительными путями на один уровень вглубь.
- `$ARGUMENTS` в теле подставит аргументы вызова `/имя args`; без
  плейсхолдера аргументы допишутся с новой строки.

## Проверка

1. Покажи пользователю черновик SKILL.md целиком.
2. Предложи 2–3 реалистичных промпта для проверки («сделай ревью моих
   изменений», «задеплой на staging»).
3. Попроси пользователя оценить результат и доработай скилл по замечаниям:
   обобщай, а не латай под один пример; объясняй «почему», а не плоди
   MUST-ы капсом; выкидывай то, что не работает.
