# Changelog

All notable changes to ChiselCode are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.2.24] - 2026-09-14

### Changed

- Убраны стартовые подсказки при запуске TUI: история начинается пустой, сервис и модель уже видны в закреплённой шапке, подсказки остались в `/help` и строке горячих клавиш.

### Fixed

- Полноэкранный режим на Windows/conhost: размер окна читается напрямую через `stdout.getWindowSize()` с подпиской на `resize` вместо одного `useWindowSize()` Ink, который отдавал 80x24 — кадр больше не рисуется сверху с чёрной пустотой снизу, ввод прижат к низу при любом размере и максимизации окна.

## [0.2.23] - 2026-09-14

### Added

- Живые сессии в чате: агент помнит предыдущие сообщения — каждый ответ продолжает ту же сессию с полной историей. Новые команды `/new` (новый сеанс), `/sessions` (список сеансов проекта), `/resume <номер>` (возврат с реплеем истории в вид); `/clear` теперь тоже начинает новый сеанс. `/status` показывает название сессии, короткий id и токены контекста. Названия сессий — из первого сообщения. Работает и в простом текстовом режиме.

## [0.2.22] - 2026-09-14

### Added

- Команда `/update` теперь обновляет приложение: проверка релиза → подтверждение y/n → скачивание установщика → запуск установки и выход. На Windows с установленным бинарником — полностью автоматически; на macOS/Linux — скачивает файл и показывает команду установки; при запуске из исходников подсказывает `git pull` и ссылку на релиз.

## [0.2.21] - 2026-09-14

### Added

- Кнопка «⇄ Проверить подключение» в `/settings`: проверяет ключ, адрес и список моделей у провайдера и показывает точную причину вместо «не работает» (401 — ключ, 404 — адрес с подсказкой про `/v1`, отсутствие модели в списке шлюза).

### Fixed

- Совместимым Anthropic-шлюзам (в т.ч. AgentRouter) больше не отправляются новые параметры `thinking: adaptive` и `output_config`: их знает только официальный API, а шлюзы отвечали 400 на весь запрос.

## [0.2.2] - 2026-09-13

### Fixed

- Починена работа через шлюз AgentRouter (`https://agentrouter.org`): OpenAI-совместимому адресу с голым хостом автоматически добавляется `/v1` (без него `/chat/completions` возвращал HTML главной вместо API), явные пути не трогаются; у Anthropic-совместимого адреса наоборот убирается хвостовой `/v1` (иначе SDK ходил бы в `/v1/v1/messages` → 404). Нормализация применяется и при сохранении настроек, и на уровне адаптеров — покрывает флаги CLI, конфиг и TUI.
- Совместимые OpenAI-шлюзы: при 400 на параметр лимита токенов запрос один раз повторяется с другим именем параметра (`max_completion_tokens` ↔ `max_tokens`) — часть шлюзов принимает только один вариант.

## [0.2.1] - 2026-09-13

### Fixed

- Исправлен вылет при выборе «↺ Пройти настройку заново» в `/settings`: мастер настройки теперь открывается внутри того же TUI-экрана, без размонтирования интерфейса и повторного `render()` Ink в том же процессе. После завершения настройки сервис, модель и адрес API применяются к текущей сессии, итог виден строкой в журнале; отмена по Ctrl+C возвращает в чат.
- Закалён список настроек: индекс выбора зажимается при смене сервиса (пункт «Адрес API» есть только у совместимых провайдеров), выбор сервиса корректно стартует с первого варианта.

## [0.2.0] - 2026-09-13

### Added

- Команда `chisel update`: проверка новой версии через GitHub Releases (`--json` для скриптов) с подсказкой файла установщика под текущую ОС; в TUI доступны `/update` и `/doctor`.
- Итоговая строка после каждого ответа в TUI: время, токены, стоимость и короткая сессия (`✓ Готово за 12с · 1 234 токенов · $0.012 · сессия abc12345`).
- Человекочитаемые сводки вызовов инструментов в журнале (`read_file src/cli.ts (строки 11–60)`, `$ bun test (в tests)`) вместо сырого JSON.
- Панель `/status` в виде дашборда с шапкой, контекстом сессии и подсказками следующих команд.
- Премиальные детали TUI: версия в закреплённой шапке, цветные заголовки по уровням, подсветка diff в блоках кода (`+`/`-`/`@@`), жирный инлайн-код, иконки пунктов настроек, прогресс-степс (`●●○○`) и подсказки провайдера в мастере настройки, тоновый тип `success`.
- Премиальный one-shot режим: именованные карточки инструментов (`⟡ [+] Запись файла …`), цветные `✓/✗/⚠` (уважает `NO_COLOR` и pipe, `--json` без изменений).
- Премиальный `chisel doctor`: шапка с версией и статусы `✓/✗` по каждой строке.

### Changed

- Справка `/help` переписана как панель с разделами и всеми командами.
- Версия CLI вынесена в единый модуль `src/version.ts`.

## [0.1.21] - 2026-09-13

### Fixed

- Исправлено «съезжание» TUI и дыры в журнале: смета высоты футера теперь учитывает перенос строки горячих клавиш, подсказок и спиннера, а префиксы ошибок/предупреждений входят в смету строк — Yoga больше не схлопывает случайные строки истории в ноль при переполнении.
- Строки истории и индикаторы прокрутки закреплены от схлопывания (`flexShrink={0}`): при неточной смете переполнение режется снизу, а не в середине журнала.
- Скролл как в Claude Code при закреплённом снизу вводе: PgUp/PgDn — постранично, Shift+↑/↓ — построчно, Home/End — начало/конец, Esc — вернуться вниз к вводу.

## [0.1.20] - 2026-09-13

### Fixed

- Полная адаптация TUI к ширине окна и полному экрану как в Claude Code: закреплённая шапка на всю ширину с динамическим разделителем, поле ввода и подтверждение прижаты к низу на всю ширину и растут вверх, текст переоборачивается при ресайзе без «съезжания» строки ввода.
- Точные оценки высоты с учётом рамок, отступов и префиксов (ввод, подтверждение, markdown с кодом/списками/заголовками), нормализация вьюпорта и полноширинные разделители в истории и markdown.

## [0.1.19] - 2026-09-12

### Fixed

- Исправлена деформация рамок и неполная перерисовка TUI после разворачивания окна: экран использует нативный `useWindowSize()` Ink вместо конкурирующего обработчика resize и не перемонтируется принудительно при каждом изменении размеров.
- Убраны вложенные процентные ширины рамок: нижняя панель, подсказки, ввод и настройки теперь растягиваются единым flex-layout без выхода за границы терминала.

## [0.1.18] - 2026-09-12

### Fixed

- Нижняя панель ввода, подсказки команд и запрос подтверждения теперь растягиваются на всю ширину терминала.
- Размер TUI надёжно синхронизируется после разворачивания, восстановления и изменения окна Windows Terminal; кадр перемонтируется с актуальными размерами.
- Историю в alternate screen можно просматривать без скроллбэка терминала: PageUp/PageDown листают журнал, Home/End переходят к началу и концу; новые сообщения возвращают просмотр к последней записи.

## [0.1.17] - 2026-09-12

### Fixed

- Интерактивный TUI теперь использует нативный alternate screen Ink 7: во время работы ChiselCode скроллбэк терминала недоступен, а после `/exit` или Ctrl+C восстанавливается исходный экран.
- Кадр TUI ограничен физическим размером терминала: история клиппится в отдельной области, а многострочный ввод, подсказки команд и запросы подтверждения закреплены снизу и корректно пересчитываются при изменении высоты или ширины окна.

## [0.1.16] - 2026-09-12

### Changed

- Полноэкранный режим как в Claude Code: приложение владеет только текущим экраном и ничего не пишет в скроллбэк терминала — листать нечего и не нужно, картинка стабильна и не «съезжает». Показывается хвост истории, влезающий в экран; над ним индикатор «… ↑ ещё N записей выше (экран полон)». Поле ввода всегда на нижней кромке окна; высота кадра пересчитывается при ресайзе.
- Оценка высоты markdown-ответов (заголовки, списки, код в рамках, перенос строк) для точного клиппинга.

## [0.1.15] - 2026-09-12

### Fixed

- Откат «прижатия» ввода через фиксированную высоту вьюпорта из v0.1.14: связка `<Static>` с динамическим кадром на весь экран ломала позиционирование курсора в Ink — текст дублировался и «съезжал». Возвращена надёжная схема Claude Code: небольшая динамическая зона (хвост стриминга + ввод) всегда внизу вывода, история уходит в скроллбэк; как только контента больше экрана, ввод оказывается на нижней кромке окна.
- Превью в панели подтверждения ограничено 12 строками, чтобы динамическая зона не раздувалась.

## [0.1.14] - 2026-09-12

### Fixed

- Поле ввода закреплено у физического нижнего края окна терминала, как в Claude Code: корневой layout занимает всю высоту вьюпорта, а растягивающийся зазор прижимает ввод и панель подтверждения к низу при любом размере истории. Длинный стриминговый ответ при переполнении экрана проливает готовую часть в скроллбэк, оставляя хвост над вводом; высота отслеживается при ресайзе окна.

## [0.1.13] - 2026-09-12

### Fixed

- Кракозябры в Windows-установщике: сборка переведена на Unicode (`Unicode true`, скрипт в UTF-8 с BOM) — русский текст на странице компонентов и в описаниях отображается корректно.

## [0.1.12] - 2026-09-12

### Added

- Опция «Ярлык на рабочем столе» в Windows-установщике (страница компонентов, по умолчанию выключена).
- Установщики для macOS (`.pkg`, arm64/x64 — ставят `chisel` в `/usr/local/bin`) и Linux (`.deb`, amd64).
- Ввод как в Claude Code: история уходит в `<Static>` и скроллится вверх, поле ввода всегда внизу; стриминговый ответ живёт отдельно и переносится в историю по завершении; подсказки команд всплывают над полем ввода; бренд-шапка — первой строкой истории.

### Changed

- Релизы содержат только установщики (Windows `.exe`, macOS `.pkg`, Linux `.deb`); отдельные бинарники больше не публикуются.

## [0.1.11] - 2026-09-12

### Added

- Красивый TUI: markdown-рендер ответов (заголовки, списки, цитаты, код в рамках, ссылки), брендированная шапка с провайдером и моделью, анимированный индикатор «Думаю…» с секундомером, панель подтверждения в рамке, поле ввода в рамке с плейсхолдером и видимым курсором, цветные тоновые строки (пользователь/инструменты/ошибки).
- Мастер настройки в рамке с индикатором шагов и подсвеченными вариантами.

## [0.1.10] - 2026-09-12

### Fixed

- Сборка установщика: пути к LICENSE и EXE в `installer/chiselcode.nsi` заданы через `${__FILEDIR__}`, так как makensis резолвит относительные пути от папки скрипта. Релиз v0.1.9 вышел без `ChiselCode-Setup-*.exe`; установщик публикуется начиная с v0.1.10.
- Тесты `resolveProjectDir`: сравнение с `realpath`, так как tmpdir может содержать симлинки (`/var` → `/private/var` на macOS, короткие имена 8.3 на Windows).

## [0.1.9] - 2026-09-12

### Added

- Windows-установщик `ChiselCode-Setup-<версия>.exe` в каждом релизе: ставится без прав администратора в `%LOCALAPPDATA%\ChiselCode`, добавляет `chisel` в пользовательский PATH, создаёт ярлыки в меню «Пуск» и деинсталлятор.
- Команда чата `/cwd <путь>`: смена папки проекта без перезапуска — можно запустить `chisel` из любого места и просто указать путь к проекту или файлу в чате. Без аргументов показывает текущую папку; новая папка начинает новую сессию.

## [0.1.8] - 2026-09-12

### Fixed

- Исправлено мгновенное закрытие `chisel-windows-x64.exe` при запуске: корневая команда теперь объявляет аргумент `[prompt...]`, поэтому `chisel "задача"` больше не падает с `too many arguments`, а запуск без аргументов открывает TUI вместо падения с объектом опций вместо промпта.
- Окно больше не исчезает без сообщения: на Windows при запуске двойным кликом (родитель — Explorer) программа ждёт Enter перед выходом, а фатальные ошибки всегда показывают подсказку про запуск из PowerShell. Флаги `--pause` / `--no-pause` управляют паузой вручную.
- Добавлен текстовый fallback-режим: если Ink не может включить raw mode в урезанной консоли, включается простой построчный интерфейс (ввод, `/help`, `/status`, `/exit`, подтверждение `y/N`), а мастер настройки работает через обычные вопросы.

## [0.1.7] - 2026-09-12

### Added

- Режим `anthropic-compatible` для прокси, которые реализуют Anthropic Messages API: `POST /v1/messages` с Bearer-токеном, отдельным базовым URL и моделью.
- Четвёртый вариант `chisel setup` и настройка `/settings` для Anthropic-совместимого API.

## [0.1.6] - 2026-09-12

### Added

- Claude Code-подобные быстрые команды в интерактивном режиме: `/help`, `/clear`, `/settings`, `/model`, `/status`, `/exit` с подсказками и автодополнением по `/`.
- Компактное безопасное меню `/settings` для смены сервиса, модели и адреса совместимого API без показа ключа.
- Многострочный редактор ввода: Enter — отправка, Shift+Enter — новая строка, ↑/↓ — история запросов, Tab — дополнить команду.

### Changed

- Изменения модели, сервиса и адреса API из настроек применяются к следующим запросам текущего сеанса.

## [0.1.5] - 2026-09-12

### Fixed

- Retry once when an OpenAI-compatible server ends a successful request without text instead of showing the internal `completed` status.
- Recognize common streamed reasoning fields without rendering private reasoning as the final answer.
- Show an actionable diagnostic if a provider still returns no final text.

## [0.1.4] - 2026-09-12

### Added

- Guided first-run setup, `chisel setup`, and a non-secret `chisel doctor` diagnostic.
- Automatic setup in interactive mode when no API key is configured.
- Beginner-focused Windows quick start and troubleshooting guide.

### Changed

- Translate the interactive welcome and approval experience into Russian.
- Explain missing API-key failures with an actionable setup command.

## [0.1.3] - 2026-09-11

### Fixed

- Include Ink's optional development-tools peer dependency in the standalone bundle dependency graph.

## [0.1.2] - 2026-09-11

### Fixed

- Run the repository-pinned Biome binary in package scripts instead of fetching a formatter dynamically.

## [0.1.1] - 2026-09-11

### Fixed

- Normalize asynchronous tool failures into structured tool results so policy violations do not terminate the agent loop.

## [0.1.0] - 2026-09-11

### Added

- Bun/TypeScript coding-agent CLI with an Ink TUI and one-shot mode.
- Anthropic, OpenAI, and OpenAI-compatible provider adapters.
- Secure project-scoped file, search, shell, and Git tools with approval previews.
- Persistent sessions, context composition, credential fallback storage, and JSON output.
- Unit and integration test coverage, formatting/lint checks, and release automation.
